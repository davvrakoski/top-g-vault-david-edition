# CHARACTER CUSTOMIZATION

=================================================

CUSTOMIZATION CATEGORIES:
- hair
- face
- skin tone
- tops
- bottoms
- shoes
- accessories
- body options
- animation set
- emotes
- colors

PIPELINE:
select -> preview locally -> validate ownership/rules -> server save -> replicate appearance.

CLOTHING:
For custom skinned clothing:
- match rig
- use clean weight painting
- test extreme poses
- avoid body clipping
- consider layer ordering
- optimize hidden body geometry only if pipeline safely supports it
