# Math Learning Path for Roblox Developers

Do not learn "college math" randomly. Learn math attached to a game problem.

1. Arithmetic/percentages — damage, UI bars, economy.
2. Algebra — formulas, progression curves.
3. Coordinate geometry — positions/distances.
4. Vectors — direction, movement, aiming.
5. Dot product — FOV/front-behind tests.
6. Trigonometry — angles, circles, procedural motion.
7. Interpolation — camera/UI/animation smoothing.
8. Probability/statistics — loot, analytics, A/B tests.
9. Linear algebra concepts — transforms/CFrame/local vs world space.
10. Calculus concepts — velocity/acceleration/change over time.

For every topic, build a Roblox demo instead of only reading equations.
