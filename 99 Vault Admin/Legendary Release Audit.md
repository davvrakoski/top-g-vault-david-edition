# Legendary Release Audit

Run this before posting the vault publicly.

## Knowledge quality
- [ ] Every major Roblox discipline has a hub or clear index entry.
- [ ] “Advanced” notes contain architecture, failure modes, tests or measurable guidance—not only definitions.
- [ ] Exact platform limits/statuses are date-stamped and linked to official sources.
- [ ] Unreal/Unity terminology is not presented as Roblox engine functionality.
- [ ] Code examples are labeled as patterns when they are not drop-in production packages.

## Graph quality
- [ ] Central Top G Vault node exists.
- [ ] Every hub has incoming/outgoing links.
- [ ] Orphans are intentional templates only.
- [ ] Zero unresolved internal wikilinks.
- [ ] Dense clusters link across domains (Combat→Animation/VFX/Audio/Networking/Performance, etc.).

## Beginner usability
- [ ] Start Here gives a learning path.
- [ ] 12-week curriculum is linked.
- [ ] Terms are defined before advanced use.
- [ ] Every system has a “what to build first” path.

## Production usability
- [ ] Reference architectures exist.
- [ ] Genre starter architectures exist.
- [ ] Security threat model exists.
- [ ] Persistence migrations and idempotency are covered.
- [ ] Performance benchmark process exists.
- [ ] Release/rollback and incident response exist.
- [ ] Current Script Sync/Rojo guidance exists.
- [ ] Current Analytics/Discovery/Monetization/Maturity snapshot exists.

## Art and visuals
- [ ] Reference decomposition method exists.
- [ ] Stylized and realistic environment workflows exist.
- [ ] PBR/material/texture guidance exists.
- [ ] Blender/AI-generated asset cleanup exists.
- [ ] VFX layering + quality tiers exist.
- [ ] Lighting/weather/water/vegetation/characters/vehicles are connected.

## Final honesty gate
Do not market the vault as guaranteeing a successful game, guaranteed income, guaranteed discovery, or universal performance numbers. Market it as a **massive, organized production knowledge system** that teaches developers how to reason, build, test and verify.
