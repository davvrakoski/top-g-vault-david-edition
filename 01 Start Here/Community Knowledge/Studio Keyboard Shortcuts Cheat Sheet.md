# Studio Keyboard Shortcuts Cheat Sheet

Shortcuts are the cheapest speed-up in Roblox development. The ones below are the defaults listed across the official Studio pages (Windows first, Mac in brackets where it differs). Every binding can be changed, and actions with no default can be bound, in **File > Customize Shortcuts**. Print this or pin it beside Studio for your first week.

## Camera (click the viewport first)

| Keys | Action |
| --- | --- |
| Right mouse + drag | Look around |
| W A S D / Q E | Fly forward, left, back, right / down, up |
| Shift + move key | Change camera speed |
| F | Focus the selected object |
| , and . | Rotate camera; orbit when an object is focused |
| Middle mouse + drag | Pan |
| Scroll, Ctrl+= / Ctrl+- (Cmd) | Zoom |

## Building and selection

| Keys | Action |
| --- | --- |
| Ctrl+D (Cmd+D) | Duplicate in place |
| Ctrl+G (Cmd+G) | Group as Model |
| Ctrl+Alt+G (Cmd+Option+G) | Group as Folder |
| Ctrl+R (Cmd+R) | Rotate selection 90 degrees around Y |
| Ctrl+T (Cmd+T) | Rotate selection 90 degrees around X |
| Ctrl+L (Cmd+L) | Toggle world / local orientation for transform tools |
| Shift+2 | Jump to the move/scale increment box |
| Alt+R (Option+R) | Jump to the rotate increment box |
| Ctrl+1 / 2 / 3 / 4 | Select / Move / Scale / Rotate tool (long-standing default, not listed on the pages we checked: unverified) |

## Explorer

| Keys | Action |
| --- | --- |
| Ctrl+Shift+X | Jump to Explorer search |
| Ctrl+V | Paste into Workspace (top level) |
| Ctrl+Shift+V | **Paste Into** the selected object |
| Right / Left arrow | Expand branch / go to parent |
| Home / End | Top / bottom of the tree |

## Testing and debugging

| Keys | Action |
| --- | --- |
| F5 | Test (spawns your avatar) |
| F8 | Run (simulate without an avatar) |
| F7 | Start Server & Clients test |
| Shift+F5 | Stop |
| F10 / F11 / Shift+F11 | Step Over / Step Into / Step Out at a breakpoint |
| Ctrl+K (Cmd+K) | Clear the Output window |

## Script Editor

| Keys | Action |
| --- | --- |
| Ctrl+P | Quick open a script by name |
| Ctrl+Shift+F | Find / replace across all scripts |
| Ctrl+F | Find / replace in this script |
| Ctrl+/ | Toggle comment |
| Alt+Up / Alt+Down | Move line up / down |
| Ctrl+Shift+K | Delete line |
| Ctrl+F12 | Go to declaration |
| Alt+F | Function list for this script |
| Alt+Shift+F | Format selection |
| Ctrl+Alt+K | Show this script in Explorer |
| Ctrl+Shift+T | Reopen last closed script |
| Ctrl+D | Add cursor at next match (multi-cursor) |
| Shift+Alt+L | Cursor on every match |

## Saving and settings

| Keys | Action |
| --- | --- |
| Alt+P (Option+P) | Publish to Roblox |
| Ctrl+Alt+S (Cmd+Option+S) | Save to Roblox with version notes |
| Alt+S (Option+S) | Studio Settings |

## During a playtest (screenshots and trailers, from the Free Camera page)

`Ctrl+Shift+C` toggles your game's on-screen GUIs, `Ctrl+Shift+G` the Roblox core UI, `Ctrl+Shift+N` nameplates and `Ctrl+Shift+B` BillboardGuis (left Shift).

## Habits worth building

- Learn **F**, **Ctrl+D** and **Ctrl+P** first; they save the most time.
- `Ctrl+V` versus `Ctrl+Shift+V` is the classic "where did my part go" mistake.
- Use **Ctrl+Alt+S** before risky edits, so Version History has a named checkpoint.
