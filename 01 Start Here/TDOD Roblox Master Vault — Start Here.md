# TDOD Roblox Master Vault — Start Here

This edition is designed as a production knowledge system, not a pile of disconnected tips.

## What makes this edition different

- 50+ baseline chapters split into searchable Obsidian notes.
- Production-grade architecture patterns and code examples.
- Current Roblox 2026 workflow guidance, including native Script Sync vs. Rojo.
- Current platform specifications for meshes, streaming, analytics, security, and maturity.
- A curriculum, project labs, review rubrics, performance budgets, and release gates.
- Claude/MCP/Git workflows designed to preserve context without forcing one giant chat.
- Open-source evaluation rules so users do not blindly paste abandoned or unsafe code.
- Every major system includes a way to test it.

## How to use it

**Beginner:** follow `17_Curriculum/01_12_Week_Curriculum.md`.

**Building a game now:** open `14_Templates_Checklists/01_PROJECT_STATE_TEMPLATE.md`, fill it in, then use the relevant technical notes.

**Using Claude:** start with `13_AI_Claude_MCP_Git/01_CLAUDE_PROJECT_INSTRUCTIONS.md` and keep `RESUME_NOTE.md` updated.

**Performance problem:** use `05_Performance_Engineering/01_Performance_Audit_Procedure.md` before changing random settings.

**Security problem:** use `03_Networking_Security/01_Threat_Model_Worksheet.md` and review every remote.
