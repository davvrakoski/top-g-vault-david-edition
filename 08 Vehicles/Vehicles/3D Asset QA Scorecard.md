# 3D Asset QA Scorecard

Score each 0–2. A production asset should not ship with any zero in a critical category.

| Category | 0 | 1 | 2 |
|---|---|---|---|
| Silhouette | unreadable | okay | excellent |
| Scale | wrong | uncertain | verified |
| Topology | broken/wasteful | usable | efficient |
| Normals | broken | minor issue | clean |
| UVs | broken | wasteful | clean |
| Texture | blurry/noisy | acceptable | role-appropriate |
| Rig/weights | broken | minor clipping | stable |
| Collision | incorrect | acceptable | intentional |
| Naming | chaotic | partial | consistent |
| Performance | unmeasured | estimated | measured |
| Import | errors | warnings | clean |
| Style | inconsistent | close | matches guide |
