# Text Chat, Moderation & Player Safety

Player communication is a gameplay feature and a safety system.

## Principles
- Use Roblox-supported chat and filtering systems.
- Never display unfiltered user-authored text to other players.
- Give players clear report/block paths.
- Log moderation-relevant server events without collecting unnecessary personal information.
- Separate community Discord moderation from in-game moderation; they have different tools and policies.

## Abuse-resistant design
Rate-limit spam-prone interactions, avoid unrestricted user-generated signs/names without filtering, and design trading/party systems so harassment cannot lock another player into an interaction.

## Moderator tools
A serious game should document: mute/kick/ban authority, evidence requirements, escalation, appeal path, false-positive handling and audit logs.

## Lab
Threat-model one social feature. List abuse cases, platform protections, server checks, user controls and moderator response.
