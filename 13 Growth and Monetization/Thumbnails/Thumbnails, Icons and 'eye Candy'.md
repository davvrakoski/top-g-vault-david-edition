# THUMBNAILS, ICONS & "EYE CANDY"

=================================================

GOAL:
Make a thumbnail look like the game a player will actually play.

ROBLOX'S OWN DISCOVERY GUIDANCE VALUES:
- accurate metadata
- unique imagery
- honest representation
- engagement/retention after click

THUMBNAIL RULES:
- one clear focal point
- readable at tiny size
- strong foreground/background separation
- 2-4 major visual elements
- clear emotion/action
- avoid microscopic details
- avoid misleading destruction/features
- use actual game style
- use real game renders/screenshots when possible
- polish lighting/composition instead of over-AI-processing

"DIAL DOWN AI GRAPHICS":
- remove hyper-sharp microdetail
- remove fake cinematic depth where game does not have it
- simplify material noise
- keep Roblox proportions
- keep consistent shadows
- avoid overbloom
- avoid random glowing edges
- avoid impossible geometry
- avoid over-composited explosions
- use believable in-game UI
- preserve Roblox visual language

THUMBNAIL COMPOSITION:
Rule of thirds.
Foreground character.
Midground action.
Background landmark.
Directional lighting points toward subject.
Leave breathing room around title/logo.

A/B TEST IDEAS:
A: character close-up
B: gameplay action
C: environment mystery
But all must truthfully represent the game.
