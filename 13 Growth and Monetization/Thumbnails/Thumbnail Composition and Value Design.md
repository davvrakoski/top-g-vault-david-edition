# Thumbnail Composition & Value Design

At small size, value structure beats detail. Use one focal subject, a readable action line and a background that supports rather than competes.

Check the thumbnail at phone-grid size and in grayscale. If the subject disappears, more effects will not fix it.

## Lab
Make one composition with no text and prove the game fantasy is still understandable.
