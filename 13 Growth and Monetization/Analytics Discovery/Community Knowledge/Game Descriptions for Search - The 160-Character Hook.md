# Game Descriptions for Search - The 160-Character Hook

Most developers write the description last, in a hurry, as a list of controls and hashtags. But the description is what Google, Bing and DuckDuckGo index, what shows under your title on mobile before "read more", and part of how a searching player decides. Since Creator Rewards pays Audience Expansion for new users who **search your game's name** and play, being findable by name is now worth Robux too. Roblox published (experimental) guidelines; this note condenses them into a template.

Note: Roblox labels these guidelines **experimental and meant for select creators**; test them, don't treat them as rules.

## The structure Roblox recommends

1. **Hook** - up to ~160 characters with your core keywords. It likely fills search snippets and is the visible part on the mobile app.
2. **Recent updates** (optional, short) - one or two lines.
3. **Main content** - the core loop and the features that make you different (bullets or a paragraph).
4. **Additional info** - device support, codes, premium benefits, a tiny FAQ, a link to a DevForum changelog/credits.

## Writing the hook

Include: the **title**, the **genre**, the **most unique feature**, and the **main objective**. Ask a question or set a goal.

- Weak: "A fun action-packed game to play with friends!"
- Better (pattern from Roblox's example): "[Title] is a fast-paced tower defense game where you build a fortress and hold off hordes. Can you survive all 500 waves?"

Match the words players actually type: the genre name ("tower defense", "obby", "tycoon"), the theme ("zombie", "anime", "pet"), and your game's name spelled exactly.

## Things Roblox explicitly advises against

- **Tags and hashtags** - unused in Roblox ranking and waste characters.
- **Listing controls** - teach them in the game's tutorial instead.
- Long FAQs that eat the ~**1000 character** budget the guide mentions.
- Anything not appropriate for all ages.

## Template (fill in)

```
[Emoji] [Title] is a [genre] game where you [main action] and [goal]. [Hook question]?

[NEW] [Update name]: [one-line summary]

- [Feature 1: core loop]
- [Feature 2: what's unique]
- [Feature 3: social / co-op]
- [Feature 4: progression / collection]

Play on PC, mobile, tablet and console. Codes: [CODE] (see Community for more).
```

## Keep it consistent

- Title, icon, thumbnails, **genre** and description should promise the same game (mismatches feel misleading and can lead to genre reassignment).
- **Localize** the description for your top languages; the hook matters most in each one.
- Update the "Recent updates" line every release, then trim old ones so the main content stays near the top.

## Measure

Descriptions are hard to A/B test directly. In Creator Analytics > **Acquisition**, compare new users with plays from the **Search** source (which Roblox defines as organic Search results plus Recommended Experiences on the details page) for the weeks before and after a rewrite. Change one thing at a time.
