# Game Design, Balancing & Difficulty

Balancing is not making every number equal; it is shaping choices and pacing.

## Start with targets
Define expected time-to-kill, encounter duration, movement speed, resource income, upgrade cadence and failure rate for the intended audience.

## Difficulty levers
Enemy health is only one lever. Use behavior, numbers, positioning, telegraphs, resource pressure, objective complexity and recovery opportunities.

## Avoid stat inflation
Doubling enemy health can make combat longer without making it more interesting. Prefer new decisions before larger numbers.

## Data + observation
Analytics can show where players fail; playtests explain why. Use both.

## Lab
Make a combat tuning sheet containing damage, attack interval, TTK and resource cost for player/enemy archetypes. Change one axis at a time.
