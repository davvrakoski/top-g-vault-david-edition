# PROJECT PLANNING

=================================================

Write a one-page game definition:

GAME:
GENRE:
TARGET PLAYER:
TARGET DEVICES:
CORE LOOP:
SESSION LENGTH:
PLAYER COUNT:
ART STYLE:
CAMERA:
INPUT:
PROGRESSION:
MONETIZATION:
SOCIAL FEATURES:
CONTENT RATING TARGET:
PERFORMANCE TARGET:
MUST-HAVE SYSTEMS:
NICE-TO-HAVE SYSTEMS:
NOT BUILDING YET:

CORE LOOP EXAMPLE:
Spawn -> Find objective -> Fight/explore -> Earn reward -> Upgrade -> Unlock new area -> Repeat.

VERTICAL SLICE RULE:
Before building a giant world, build one polished 5-10 minute slice containing:
- movement
- one enemy
- one objective
- one reward
- one menu
- one save/load path
- one complete visual area
- one audio pass
- one optimized combat loop

If that is not fun, adding 50 maps will not fix it.
