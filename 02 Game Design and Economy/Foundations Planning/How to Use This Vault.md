# HOW TO USE THIS VAULT

=================================================

Recommended Obsidian workflow:
- Keep this file as the master reference.
- Split major sections into individual .md notes later if you want faster searching.
- Create a PROJECT_STATE.md file for the current game.
- Create a BUGS.md file.
- Create a DECISIONS.md file.
- Create a TODO.md file.
- Create a RESUME_NOTE.md file.
- Create a PERFORMANCE_BUDGET.md file.
- Create a STYLE_GUIDE.md file.
- Create a SOURCES.md file.
- Create a TEST_RESULTS.md file.

When giving the vault to Claude:
1. Tell Claude to read PROJECT_STATE.md first.
2. Tell it to read STYLE_GUIDE.md second.
3. Tell it to read only the relevant technical notes for the current task.
4. Tell it NOT to rewrite working systems unless necessary.
5. Tell it to identify dependencies before editing.
6. Tell it to make small, testable changes.
7. Tell it to record what it changed.
8. Tell it to update RESUME_NOTE.md at the end of a work session.

Good AI instruction:
"Do not guess the project structure. Inspect it first. Explain what you found, identify the smallest safe change, make the change, test it, and document the result."

Bad AI instruction:
"Make everything better."
