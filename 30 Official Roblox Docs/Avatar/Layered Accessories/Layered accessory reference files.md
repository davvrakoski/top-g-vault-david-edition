*Download various project files and reference files for layered accessories.*

The following `.fbx`, `.blend`, and `.ma` template and reference project files are specifically helpful when creating a layered accessory for an avatar. For a comprehensive list of Roblox's official downloadable content for avatars, such as character bodies and rigid accessory templates, see [[30 Official Roblox Docs/Avatar/Resources|Resources]].

### Blender

| **File** | **Description** |
| --- | --- |
| [Rig_and_Attachments_Template.blend](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/Rig_and_Attachments_Templates.zip) | Starting rigging armature template for Blender. | [Combined-Template.blend](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/Combined_Templates.zip) | Template file containing all content from previous templates, includes a rigging armature, body cages, and attachment points. Use this template to rig and cage character bodies and accessories. |
