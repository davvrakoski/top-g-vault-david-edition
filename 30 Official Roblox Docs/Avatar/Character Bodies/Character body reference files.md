*Download various project files and reference files for character bodies.*

The following project files and templates are specifically helpful when creating a character body for an avatar. For a comprehensive list of Roblox's official downloadable content for avatars, such as rigid and layered accessory templates, see [[30 Official Roblox Docs/Avatar/Resources|Resources]].

## Project files

The following `.fbx`, `.blend`, and `.ma` project files are available to use as examples, boilerplate, or as a reference for your own custom character bodies for avatars:

## Templates

If you are creating custom character body models, you can choose from a variety of starting templates that best match your final design to save time on creating the [[30 Official Roblox Docs/Avatar/Character Bodies/Character bodies#Character body components|avatar components]]. For important information on using these template files, see [[30 Official Roblox Docs/Art/Characters/Creating/Create with templates|Create with templates]].

Each `.zip` contains a `.blend`, `.fbx`, and PBR texture `.png` files for that template model. If using Blender or following the [[30 Official Roblox Docs/Art/Characters/Creating/Create with templates|template creation guides]], use the `.blend` project.

> [!warning]
> If you are using Roblox's avatar template files, you must perform the [[30 Official Roblox Docs/Art/Characters/Creating/Combine head geometry|cleanup steps]] in order for the assets to properly validate before publishing to the Marketplace.
