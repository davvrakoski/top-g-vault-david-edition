*Determines whether an [[30 Official Roblox Docs/API Reference/Classes/Explosion|Explosion]] creates craters when it detonates.*

## Description

The ExplosionType Enum is used to set the [[30 Official Roblox Docs/API Reference/Classes/Explosion#ExplosionType|Explosion.ExplosionType]] property.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `NoCraters` | 0 | Explosion does not generate craters. |
| `Craters` | 1 | Explosion generates craters. |
