*Specifies the type of physical joint created when importing a rigged asset.*

## Description

Controls which joint class connects bones in an imported rig skeleton.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `AnimationConstraint` | 0 | Import creates [[30 Official Roblox Docs/API Reference/Classes/AnimationConstraint\|AnimationConstraint]] instances to connect the rig's bone joints. |
| `Motor6D` | 1 | Import creates [[30 Official Roblox Docs/API Reference/Classes/Motor6D\|Motor6D]] instances to connect the rig's bone joints. |
