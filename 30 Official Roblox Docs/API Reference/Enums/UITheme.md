*Deprecated Studio UI color theme (`Light` or `Dark`).*

> [!warning] Deprecated
> This enum refers to a deprecated setting and should not be used for new work.
> Use `Class.Studio.Theme` (`Class.StudioTheme`) instead.

## Description

A deprecated enum that previously represented the Studio UI color theme. It was exposed through the `UI_Theme` property (also deprecated) and contained [[30 Official Roblox Docs/API Reference/Enums/UITheme|Enum.UITheme.Light]] and [[30 Official Roblox Docs/API Reference/Enums/UITheme|Enum.UITheme.Dark]]. The enum is retained only for backward compatibility with existing plugins that reference it; it has no effect. Use [[30 Official Roblox Docs/API Reference/Classes/Studio#Theme|Studio.Theme]] to read or set the current [[30 Official Roblox Docs/API Reference/Classes/StudioTheme|StudioTheme]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Light` | 0 | **Deprecated.** The light Studio UI color theme. Deprecated; has no effect. |
| `Dark` | 1 | **Deprecated.** The dark Studio UI color theme. Deprecated; has no effect. |
