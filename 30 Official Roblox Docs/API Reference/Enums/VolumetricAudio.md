*Controls how the engine renders volumetric audio effects.*

## Description

Controls how the engine renders volumetric audio effects, allowing sound to emanate from the surface of a [[30 Official Roblox Docs/API Reference/Classes/Part|Part]] rather than a single point in space.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Disabled` | 0 | Volumetric audio is disabled; sound emanates from a single point. |
| `Automatic` | 1 | Currently equivalent to [[30 Official Roblox Docs/API Reference/Enums/VolumetricAudio\|Enum.VolumetricAudio.Disabled]]. |
| `Enabled` | 2 | Volumetric audio is enabled; sound emanates from the object's volume. |
