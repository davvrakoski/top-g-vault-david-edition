*Describes the type of ad creative currently rendered by an [[30 Official Roblox Docs/API Reference/Classes/AdGui|AdGui]].*

## Description

Describes the type of ad creative that an [[30 Official Roblox Docs/API Reference/Classes/AdGui|AdGui]] is currently rendering on its surface. Managed by the engine based on the creative asset served to the ad slot.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `None` | 0 | The [[30 Official Roblox Docs/API Reference/Classes/AdGui\|AdGui]] has no ad creative loaded and is not rendering ad content. |
| `Image` | 1 | The [[30 Official Roblox Docs/API Reference/Classes/AdGui\|AdGui]] is rendering a static image ad creative. |
| `Video` | 2 | The [[30 Official Roblox Docs/API Reference/Classes/AdGui\|AdGui]] is rendering a video ad creative. |
