*Enum used with [[30 Official Roblox Docs/API Reference/Datatypes/TweenInfo#new|TweenInfo.new()]] to control the direction [[30 Official Roblox Docs/API Reference/Classes/Tween|Tweens]] play in.*

## Description

These enum values are passed to [[30 Official Roblox Docs/API Reference/Datatypes/TweenInfo#new|TweenInfo.new()]] to control the direction [[30 Official Roblox Docs/API Reference/Classes/Tween|Tweens]] play in.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `In` | 0 | The easing style is applied in a forward direction. |
| `Out` | 1 | The easing style is applied in a reverse direction. |
| `InOut` | 2 | The easing style is applied forward for the first half and in reverse for the second half. |
