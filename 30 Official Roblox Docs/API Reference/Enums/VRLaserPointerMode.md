*Specifies the display mode of the VR laser pointer used to interact with the user interface.*

## Description

Specifies the display mode of the laser pointer that a VR player uses to interact with the user interface. This enum is the type of [[30 Official Roblox Docs/API Reference/Classes/VRService#LaserPointer|VRService.LaserPointer]], which defaults to [[30 Official Roblox Docs/API Reference/Enums/VRLaserPointerMode|Pointer]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Disabled` | 0 | The laser pointer is hidden and no pointer is rendered for any VR hand. |
| `Pointer` | 1 | A single laser pointer is shown for the primary VR hand; this is the default value of [[30 Official Roblox Docs/API Reference/Classes/VRService#LaserPointer\|VRService.LaserPointer]]. |
| `DualPointer` | 2 | A laser pointer is shown for each VR hand simultaneously. |
