## Description

Used by [[30 Official Roblox Docs/API Reference/Classes/LayerCollector#ZIndexBehavior|LayerCollector.ZIndexBehavior]] to control how the [[30 Official Roblox Docs/API Reference/Classes/GuiObject#ZIndex|GuiObject.ZIndex]] property behaves for descendants.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Global` | 0 | The ZIndex property overrides the default value computed from the depth in the hierarchy. |
| `Sibling` | 1 | The ZIndex property controls the order in which the GuiObject renders relative to its siblings. |
