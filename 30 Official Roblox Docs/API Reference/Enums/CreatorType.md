*Indicates whether the currently running place is owned by an individual user or a group.*

## Description

Indicates whether the currently running place is owned by an individual user ([[30 Official Roblox Docs/API Reference/Enums/CreatorType|Enum.CreatorType.User]]) or a group ([[30 Official Roblox Docs/API Reference/Enums/CreatorType|Enum.CreatorType.Group]]). Read from properties such as [[30 Official Roblox Docs/API Reference/Classes/DataModel#CreatorType|DataModel.CreatorType]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `User` | 0 | The place is owned by a single user. |
| `Group` | 1 | The place is owned by a group. |
