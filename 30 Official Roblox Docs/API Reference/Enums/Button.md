## Description

Used for accessing buttons for use by the [[30 Official Roblox Docs/API Reference/Classes/Controller|Controller]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Dismount` | 8 | Represents the dismount action that can be bound on a [[30 Official Roblox Docs/API Reference/Classes/Controller\|Controller]] to detect when a player triggers the dismount input. |
