## Description

Values for [[30 Official Roblox Docs/API Reference/Classes/Workspace#IKControlConstraintSupport|Workspace.IKControlConstraintSupport]]. Sets the support for constraints for [[30 Official Roblox Docs/API Reference/Classes/IKControl|IKControls]] in your experience.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | The default option for [[30 Official Roblox Docs/API Reference/Classes/IKControl\|IKControls]]. The default is currently set to `Enabled`. |
| `Disabled` | 1 | Disables support for constraints for [[30 Official Roblox Docs/API Reference/Classes/IKControl\|IKControls]]. When disabled, [[30 Official Roblox Docs/API Reference/Classes/IKControl\|IKControls]] still work, but ignore physics constraints. |
| `Enabled` | 2 | Enables support for constraints for [[30 Official Roblox Docs/API Reference/Classes/IKControl\|IKControls]]. |
