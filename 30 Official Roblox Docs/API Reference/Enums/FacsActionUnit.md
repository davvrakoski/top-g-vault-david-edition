*Identifies a Facial Action Coding System pose for facial animation.*

## Description

Represents a Facial Action Coding System (FACS) pose used by [[30 Official Roblox Docs/API Reference/Classes/EditableMesh|EditableMesh]] facial-animation methods such as [[30 Official Roblox Docs/API Reference/Classes/EditableMesh#GetFacsPose|EditableMesh:GetFacsPose()]] and [[30 Official Roblox Docs/API Reference/Classes/EditableMesh#SetFacsPose|EditableMesh:SetFacsPose()]].

| Name | Value | Summary |
| --- | --- | --- |
| `ChinRaiserUpperLip` | 0 | Moves the upper lip upward when the chin raiser is engaged. |
