*Determines vertical alignment of text.*

## Description

Determines vertical alignment of text.

Used by [[30 Official Roblox Docs/API Reference/Classes/TextLabel#TextYAlignment|TextLabel]], [[30 Official Roblox Docs/API Reference/Classes/TextButton#TextYAlignment|TextButton]], and [[30 Official Roblox Docs/API Reference/Classes/TextBox#TextYAlignment|TextBox]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Top` | 0 | Alignment starts at the top of the GUI object. |
| `Center` | 1 | Aligned starts at the center of the GUI object and spreads equally toward the top and bottom. |
| `Bottom` | 2 | Alignment starts at the bottom of the GUI object. |
