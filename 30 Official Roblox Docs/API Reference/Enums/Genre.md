## Description

`Genre` categorizes an experience by its play-style theme. Its only consumer is the [[30 Official Roblox Docs/API Reference/Classes/DataModel#Genre|DataModel.Genre]] property, which is deprecated and no longer functional — reading [[30 Official Roblox Docs/API Reference/Classes/DataModel#Genre|DataModel.Genre]] may throw an error. The enum values are listed here for reference only; new experiences should not depend on this enum.
