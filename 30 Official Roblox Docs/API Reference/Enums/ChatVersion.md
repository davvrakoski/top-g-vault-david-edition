## Description

Determines whether [[30 Official Roblox Docs/API Reference/Classes/TextChatService|TextChatService]] should be fully enabled or to allow the legacy system.

[[30 Official Roblox Docs/API Reference/Classes/TextChatService#ChatVersion|TextChatService.ChatVersion]] is not scriptable and must be set in Studio.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `LegacyChatService` | 0 | Enables the legacy chat system. |
| `TextChatService` | 1 | Enables [[30 Official Roblox Docs/API Reference/Classes/TextChatService\|TextChatService]] chat and prevents legacy chat system behavior. |
