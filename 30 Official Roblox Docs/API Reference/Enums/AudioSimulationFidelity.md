*Enum which determines how detailed audio simulation should be for [[30 Official Roblox Docs/API Reference/Classes/AudioEmitter|AudioEmitters]] and [[30 Official Roblox Docs/API Reference/Classes/AudioListener|AudioListeners]].*

## Description

This enum, used with [[30 Official Roblox Docs/API Reference/Classes/AudioEmitter#SimulationFidelity|AudioEmitter.SimulationFidelity]] and [[30 Official Roblox Docs/API Reference/Classes/AudioListener#SimulationFidelity|AudioListener.SimulationFidelity]], determines how detailed audio simulation should be.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `None` | 0 | No acoustic simulation occurs; only direction and distance are taken into account. |
| `Automatic` | 1 | The audio engine simulates transmission, diffraction, and reflections at a level of detail suitable to most devices. |
