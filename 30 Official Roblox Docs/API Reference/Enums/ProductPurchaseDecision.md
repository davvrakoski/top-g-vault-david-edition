## Description

The `ProductPurchaseDecisionEnum` is used to work with [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService|MarketplaceService]], and the sale of developer products.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `NotProcessedYet` | 0 | The purchase request has been sent but not yet processed. |
| `PurchaseGranted` | 1 | The purchase has been processed and granted to the user who initiated the purchase request. |
