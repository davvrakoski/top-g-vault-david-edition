## Description

Used by [[30 Official Roblox Docs/API Reference/Classes/UIStroke#StrokeSizingMode|UIStroke.StrokeSizingMode]] to determine whether the stroke's [[30 Official Roblox Docs/API Reference/Classes/UIStroke#Thickness|Thickness]] will be measured in pixels or be relative to the parent.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `FixedSize` | 0 | [[30 Official Roblox Docs/API Reference/Classes/UIStroke#Thickness\|Thickness]] is measured in pixels. |
| `ScaledSize` | 1 | [[30 Official Roblox Docs/API Reference/Classes/UIStroke#Thickness\|Thickness]] is relative to minimum parent width or height. If stroke is on text, thickness is relative to font size. |
