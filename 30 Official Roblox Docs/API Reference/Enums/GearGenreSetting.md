*Controls which gear genres are permitted in a place.*

> [!warning] Deprecated
> This enum is deprecated as it is used by deprecated properties that are no
> longer functional. It should not be used.

- **Tags:** `Deprecated`

## Description

The GearGenreSetting Enum sets what types of gear are allowed in a place.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `AllGenres` | 0 | **Deprecated.** All gear genres are allowed. |
| `MatchingGenreOnly` | 1 | **Deprecated.** Only gear genres matching the allowed genres specified in a place's configuration settings. |
