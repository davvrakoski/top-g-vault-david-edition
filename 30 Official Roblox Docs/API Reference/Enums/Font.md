*Determines the font used to render text in GUI objects such as Class.TextLabel, Class.TextButton, and Class.TextBox. This is a legacy property. For new work, use [[30 Official Roblox Docs/API Reference/Datatypes/Font|Font]], [[30 Official Roblox Docs/API Reference/Classes/TextLabel#FontFace|FontFace]], and [[30 Official Roblox Docs/API Reference/Classes/TextButton#FontFace|FontFace]] instead.*

## Description

The `Font` enum is used in [[30 Official Roblox Docs/API Reference/Classes/TextBox|TextBox]], [[30 Official Roblox Docs/API Reference/Classes/TextLabel|TextLabel]], [[30 Official Roblox Docs/API Reference/Classes/TextButton|TextButton]], and similar GUI objects to determine how the element will render its text.

See also [[30 Official Roblox Docs/API Reference/Datatypes/Font|Font]] as a newer alternative to this enum which encapsulates fonts as a datatype and provides access to more fonts than this enum allows.
