## Description

Represents the user's saved graphics quality preference, stored in [[30 Official Roblox Docs/API Reference/Classes/UserGameSettings#SavedQualityLevel|UserGameSettings.SavedQualityLevel]]. When set to [[30 Official Roblox Docs/API Reference/Enums/SavedQualitySetting|Enum.SavedQualitySetting.Automatic]], the engine selects quality automatically based on device performance; otherwise the chosen level (1–10) is persisted across sessions and applied as the initial quality setting on next launch.
