*Determines horizontal alignment of text.*

## Description

Determines horizontal alignment of text.

Used by [[30 Official Roblox Docs/API Reference/Classes/TextLabel#TextXAlignment|TextLabel]], [[30 Official Roblox Docs/API Reference/Classes/TextButton#TextXAlignment|TextButton]], and [[30 Official Roblox Docs/API Reference/Classes/TextBox#TextXAlignment|TextBox]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Left` | 0 | Alignment starts at the left side of the GUI object. |
| `Right` | 1 | Alignment starts at the right side of the GUI object. |
| `Center` | 2 | Aligned starts at the center of the GUI object and spreads equally left and right. |
