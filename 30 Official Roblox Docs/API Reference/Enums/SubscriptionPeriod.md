*Describes the billing period for a [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService|MarketplaceService]] subscription product.*

## Description

Describes the recurring billing interval of a subscription product sold through [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService|MarketplaceService]]. The value is returned in the `SubscriptionPeriod` field of the dictionary produced by [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService#GetSubscriptionProductInfoAsync|MarketplaceService:GetSubscriptionProductInfoAsync()]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Month` | 0 | The subscription renews on a monthly billing cycle. |
