*Specifies the orientation of the Output panel in Roblox Studio.*

## Description

`OutputLayoutMode` controls how the Output panel is oriented and docked within the Roblox Studio window. The selected value is exposed through the `Output Layout Mode` property on the [[30 Official Roblox Docs/API Reference/Classes/Studio|Studio]] settings object. Defaults to [[30 Official Roblox Docs/API Reference/Enums/OutputLayoutMode|Enum.OutputLayoutMode.Vertical]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Horizontal` | 0 | Docks the Output panel horizontally along the top or bottom edge of the Studio window. |
| `Vertical` | 1 | Docks the Output panel vertically along the left or right edge of the Studio window. |
