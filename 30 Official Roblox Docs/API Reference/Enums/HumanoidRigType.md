*Describes whether or not a character is using an R15 rig or the legacy R6 rig.*

## Description

Describes whether or not a character is using an [[30 Official Roblox Docs/Avatar/Character Bodies/Character body specifications#Rigging|R15 rig]] or the legacy R6 rig, as returned by the [[30 Official Roblox Docs/API Reference/Classes/Humanoid#RigType|Humanoid.RigType]] property.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `R6` | 0 | Indicates that a character is using the legacy R6 rig. |
| `R15` | 1 | Indicates that a character is using an R15 rig. |
