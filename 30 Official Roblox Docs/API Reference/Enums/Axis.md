*One of the 3D axes.*

## Description

The Axis Enum represents the X, Y and Z axes. Primarily this Enum is used with [[30 Official Roblox Docs/API Reference/Classes/ArcHandles|ArcHandles]] and [[30 Official Roblox Docs/API Reference/Classes/Handles|Handles]].

| `Y` | 1 | The Y axis. |
| `Z` | 2 | The Z axis. |
