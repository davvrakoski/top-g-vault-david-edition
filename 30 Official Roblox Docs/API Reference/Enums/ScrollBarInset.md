*This enum is used with [[30 Official Roblox Docs/API Reference/Classes/ScrollingFrame#HorizontalScrollBarInset|ScrollingFrame.HorizontalScrollBarInset]] and [[30 Official Roblox Docs/API Reference/Classes/ScrollingFrame#VerticalScrollBarInset|ScrollingFrame.VerticalScrollBarInset]] to indicate whether the canvas should be inset by [[30 Official Roblox Docs/API Reference/Classes/ScrollingFrame#ScrollBarThickness|ScrollBarThickness]] for the respective scroll bar.*

## Description

This enum is used with [[30 Official Roblox Docs/API Reference/Classes/ScrollingFrame#HorizontalScrollBarInset|ScrollingFrame.HorizontalScrollBarInset]] and [[30 Official Roblox Docs/API Reference/Classes/ScrollingFrame#VerticalScrollBarInset|ScrollingFrame.VerticalScrollBarInset]] to indicate whether the canvas should be inset by [[30 Official Roblox Docs/API Reference/Classes/ScrollingFrame#ScrollBarThickness|ScrollBarThickness]] for the respective scroll bar.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `None` | 0 | The canvas will never be inset for the respective scroll bar. |
| `ScrollBar` | 1 | The canvas will only be inset if the respective scroll bar is showing. |
| `Always` | 2 | The canvas will always be inset for the respective scroll bar, regardless of whether that scroll bar is showing. |
