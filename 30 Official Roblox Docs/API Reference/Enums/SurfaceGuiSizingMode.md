## Description

Used by [[30 Official Roblox Docs/API Reference/Classes/SurfaceGui#SizingMode|SurfaceGui.SizingMode]] to control the sizing behavior of a [[30 Official Roblox Docs/API Reference/Classes/SurfaceGui|SurfaceGui]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `FixedSize` | 0 | Renders with a fixed size set using [[30 Official Roblox Docs/API Reference/Classes/SurfaceGui#CanvasSize\|SurfaceGui.CanvasSize]]. |
| `PixelsPerStud` | 1 | Renders with a variable size based on [[30 Official Roblox Docs/API Reference/Classes/SurfaceGui#PixelsPerStud\|SurfaceGui.PixelsPerStud]] and the SurfaceGui's size in studs. |
