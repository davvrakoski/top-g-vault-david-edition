*Determines whether anti-aliasing is applied when drawing on the instance.*

## Description

Determines whether anti-aliasing is applied when drawing on the instance.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Disabled` | 0 | Disables anti-aliasing, resulting in hard edges. |
| `Enabled` | 1 | Enables anti-aliasing, resulting in soft edges. |
