## Description

Describes the action to take when a [[30 Official Roblox Docs/API Reference/Datatypes/PathWaypoint|PathWaypoint]] is reached.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Walk` | 0 | Walk action needed to reach the next waypoint. |
| `Jump` | 1 | Jump action needed to reach the next waypoint. |
| `Custom` | 2 | A developer-defined custom action is needed to traverse a [[30 Official Roblox Docs/API Reference/Classes/PathfindingLink\|PathfindingLink]] to reach the next waypoint. |
