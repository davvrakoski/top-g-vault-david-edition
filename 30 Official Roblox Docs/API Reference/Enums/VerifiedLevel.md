## Description

Specifies the level of player verification required by [[30 Official Roblox Docs/API Reference/Classes/Player#IsVerified|Player:IsVerified()]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Low` | 0 | Requires the player to meet the low verification level or higher. This is the default value for [[30 Official Roblox Docs/API Reference/Classes/Player#IsVerified\|Player:IsVerified()]]. |
| `High` | 1 | Requires the player to meet the high verification level. |
