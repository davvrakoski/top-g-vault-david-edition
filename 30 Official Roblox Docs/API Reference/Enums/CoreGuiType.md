## Description

This enum represents all available [[30 Official Roblox Docs/API Reference/Classes/CoreGui|CoreGui]] "types" such as the [[30 Official Roblox Docs/API Reference/Classes/Backpack|Backpack]] and text chat window.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `PlayerList` | 0 | Dynamically updated [[30 Official Roblox Docs/API Reference/Classes/Players\|Players]] list, commonly used as a [[30 Official Roblox Docs/Players/Leaderboards\|leaderboard]]. |
| `Health` | 1 | The character's [[30 Official Roblox Docs/API Reference/Classes/Humanoid#Health\|Health]] bar. |
| `Backpack` | 2 | The character's [[30 Official Roblox Docs/API Reference/Classes/Backpack\|Backpack]] which contains [[30 Official Roblox Docs/Players/In-game tools\|in‑experience tools]]. |
| `Chat` | 3 | The [[30 Official Roblox Docs/Chat/Text chat overview\|text chat]] window. |
| `All` | 4 | Refers to all available core UI. |
| `EmotesMenu` | 5 | Popup menu of character [[30 Official Roblox Docs/Characters/Emotes\|emotes]]. |
| `SelfView` | 6 | A player's perspective or view of their own character. |
| `Captures` | 7 | A "capture" button along the right side of the screen. |
| `AvatarSwitcher` | 8 | The **Avatar Switcher** allows users to change their platform avatar. |
| `ExperienceShop` | 9 | The in-experience shop overlay that lets players browse and purchase items without leaving the experience. |
