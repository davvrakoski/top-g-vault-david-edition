*The completion status of a [[30 Official Roblox Docs/API Reference/Classes/GuiObject|GuiObject]] tween function.*

## Description

Describes the completion status of a [[30 Official Roblox Docs/API Reference/Classes/GuiObject|GuiObject]] tween function.

Passed as an argument to the callback function provided to [[30 Official Roblox Docs/API Reference/Classes/GuiObject#TweenPosition|GuiObject:TweenPosition()]], [[30 Official Roblox Docs/API Reference/Classes/GuiObject#TweenSize|GuiObject:TweenSize()]], and [[30 Official Roblox Docs/API Reference/Classes/GuiObject#TweenSizeAndPosition|GuiObject:TweenSizeAndPosition()]].

Not to be confused for [[30 Official Roblox Docs/API Reference/Enums/PlaybackState|Enum.PlaybackState]] which is used with [[30 Official Roblox Docs/API Reference/Classes/TweenService|TweenService]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Canceled` | 0 | The tween was cancelled before completion. |
| `Completed` | 1 | The Tween has successfully completed. |
