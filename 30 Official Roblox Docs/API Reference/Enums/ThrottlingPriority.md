*Amount of throttling to apply.*

## Description

Controls the amount of throttling under the [HttpRbxApiService](https://create.roblox.com/docs/reference/engine/classes/HttpRbxApiService).

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Standard throttling. |
| `ElevatedOnServer` | 1 | Less throttling if on the server. |
| `Extreme` | 2 | No throttling, absolutely no exceptions. |
