## Description

The `FontSize` enum controls the font size of text in [[30 Official Roblox Docs/API Reference/Classes/TextBox|TextBox]], [[30 Official Roblox Docs/API Reference/Classes/TextLabel|TextLabel]], [[30 Official Roblox Docs/API Reference/Classes/TextButton|TextButton]], and similar objects.
