*Controls the [[30 Official Roblox Docs/API Reference/Classes/Part#Shape|Part.Shape]] of an object.*

## Description

The **PartType** enum specifies the primitive geometry shape of a [[30 Official Roblox Docs/API Reference/Classes/Part|Part]], assigned through its [[30 Official Roblox Docs/API Reference/Classes/Part#Shape|Shape]] property. A new [[30 Official Roblox Docs/API Reference/Classes/Part|Part]] defaults to `Block`. The five available shapes are Ball (sphere), Block (rectangular prism), Cylinder (oriented along the X axis), Wedge (a ramp with a slope on one face), and CornerWedge (a ramp with slopes on two perpendicular faces).

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Ball` | 0 | A spherical shape. |
| `Block` | 1 | A block shape. |
| `Cylinder` | 2 | A cylinder shape oriented along the **X** axis. |
| `Wedge` | 3 | A wedge shape with a slope on one side. |
| `CornerWedge` | 4 | A wedge shape with slopes on two sides. |
