*Controls whether the experimental Primal Physics Solver is enabled.*

## Description

An experimental constraint solver that can improve accuracy in complex setups. This enum is used by [[30 Official Roblox Docs/API Reference/Classes/Workspace#PrimalPhysicsSolver|Workspace.PrimalPhysicsSolver]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Uses the engine-default physics solver state. |
| `Experimental` | 1 | The experimental Primal Physics Solver is enabled. |
| `Disabled` | 2 | The Primal Physics Solver is disabled. |
