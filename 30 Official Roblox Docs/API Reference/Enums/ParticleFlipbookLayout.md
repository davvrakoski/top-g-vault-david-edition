*Determines the layout of the flipbook texture.*

## Description

Determines the layout of the flipbook texture.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `None` | 0 | Disable flipbook features and use the texture as a single static texture over the particle's lifetime. |
| `Grid2x2` | 1 | 2×2 frames for a 4-frame animation. |
| `Grid4x4` | 2 | 4×4 frames for a 16-frame animation. |
| `Grid8x8` | 3 | 8×8 frames for a 64-frame animation. |
| `Custom` | 4 | A custom grid size defined by [[30 Official Roblox Docs/API Reference/Classes/ParticleEmitter#FlipbookSizeX\|FlipbookSizeX]] and [[30 Official Roblox Docs/API Reference/Classes/ParticleEmitter#FlipbookSizeY\|FlipbookSizeY]]. |
