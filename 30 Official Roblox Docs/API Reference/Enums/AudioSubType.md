*The categorization of an audio asset.*

## Description

The categorization of an audio asset between music and sound effects. This categorization is used for filtering audio in [[30 Official Roblox Docs/API Reference/Classes/AudioSearchParams|AudioSearchParams]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Music` | 1 | Represents an asset which contains music. |
| `SoundEffect` | 2 | Represents an asset which is a sound effect. |
