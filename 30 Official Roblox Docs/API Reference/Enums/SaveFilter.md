*Used by [[30 Official Roblox Docs/API Reference/Classes/DataModel#SavePlace|DataModel.SavePlace]] to determine the type of save operation This enum determines which aspects of the current place are saved, based on the following options.*

> [!warning] Deprecated
> This deprecated enum is used by `Class.DataModel.SavePlace` which has also
> been deprecated. Neither should be used in new work.

- **Tags:** `Deprecated`

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `SaveWorld` | 0 | Saves only the world-related data. |
| `SaveGame` | 1 | Saves only the game-related data. |
| `SaveAll` | 2 | Saves all data, including both world and game-related information. |
