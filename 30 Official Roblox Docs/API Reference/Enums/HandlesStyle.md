*Determines the visual style of [[30 Official Roblox Docs/API Reference/Classes/Handles|Handles]] object handles.*

## Description

Determines the visual style of [[30 Official Roblox Docs/API Reference/Classes/Handles|Handles]] object handles. Setting [[30 Official Roblox Docs/API Reference/Classes/Handles#Style|Handles.Style]] to a value from this enum controls whether the handles rendered on each face of the adornee appear as spheres ([[30 Official Roblox Docs/API Reference/Enums/HandlesStyle|Enum.HandlesStyle.Resize]]) or as directional arrows ([[30 Official Roblox Docs/API Reference/Enums/HandlesStyle|Enum.HandlesStyle.Movement]]). The default value of [[30 Official Roblox Docs/API Reference/Classes/Handles#Style|Handles.Style]] is [[30 Official Roblox Docs/API Reference/Enums/HandlesStyle|Enum.HandlesStyle.Resize]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Resize` | 0 | Renders [[30 Official Roblox Docs/API Reference/Classes/Handles\|Handles]] as sphere shapes for resizing an adornee along its face axes (the default style). |
| `Movement` | 1 | Renders [[30 Official Roblox Docs/API Reference/Classes/Handles\|Handles]] as directional arrow shapes for translating an adornee along its face axes. |
