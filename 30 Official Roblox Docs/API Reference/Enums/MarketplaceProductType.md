*Indicates if an avatar item is an asset or bundle. Used with MarketplaceService and similar services.*

## Description

Indicates if an avatar item is an asset or bundle. Used with [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService|MarketplaceService]] and similar services.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `AvatarAsset` | 1 | A standalone avatar item (such as an accessory, clothing, or body part) sold individually in the Avatar Shop. |
| `AvatarBundle` | 2 | A curated collection of avatar items sold together as a single package in the Avatar Shop. |
