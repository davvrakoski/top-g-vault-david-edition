*Determines the coordinate space used when dragging objects in Studio.*

## Description

Determines the coordinate space in which the Studio dragger moves and orients selected objects. Used as the type of the [[30 Official Roblox Docs/API Reference/Classes/DraggerService#DraggerCoordinateSpace|DraggerService.DraggerCoordinateSpace]] property, which defaults to [[30 Official Roblox Docs/API Reference/Enums/DraggerCoordinateSpace|Enum.DraggerCoordinateSpace.Object]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Object` | 0 | Dragging is performed relative to the object's local coordinate space. |
| `World` | 1 | Dragging is performed relative to the world coordinate space. |
