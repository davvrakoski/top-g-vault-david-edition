*The size of textures produced by [[30 Official Roblox Docs/API Reference/Classes/VideoSampler|VideoSampler]].*

## Description

Controls the resolution of textures produced by [[30 Official Roblox Docs/API Reference/Classes/VideoSampler|VideoSampler]]. Use the smallest resolution that meets your needs to minimize memory usage and improve sampling performance.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Small` | 0 | Use when the video sample is displayed on roughly a quarter of the screen. |
| `Medium` | 1 | Use when the video sample is displayed on roughly half the screen. |
| `Large` | 2 | Use when the video sample is displayed on roughly three quarters of the screen. |
| `Full` | 3 | Use when the video sample is displayed full screen. |
