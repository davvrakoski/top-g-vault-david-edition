*Controls whether and how the player's VR hand controller models are rendered in an experience.*

## Description

`VRControllerModelMode` is used by the [[30 Official Roblox Docs/API Reference/Classes/VRService#ControllerModels|VRService.ControllerModels]] property to determine how the 3D models representing a VR player's hand controllers are displayed.

The default value of [[30 Official Roblox Docs/API Reference/Classes/VRService#ControllerModels|VRService.ControllerModels]] is [[30 Official Roblox Docs/API Reference/Enums/VRControllerModelMode|Transparent]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Disabled` | 0 | The player's VR hand controller models are not rendered. |
| `Transparent` | 1 | The player's VR hand controller models are rendered with transparency. |
