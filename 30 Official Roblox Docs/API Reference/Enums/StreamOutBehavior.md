## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Default behavior (subject to change). |
| `LowMemory` | 1 | Only stream out when memory is low. |
| `Opportunistic` | 2 | Stream out content that is significantly outside of the current [[30 Official Roblox Docs/API Reference/Classes/Workspace#StreamingTargetRadius\|Workspace.StreamingTargetRadius]]. |
