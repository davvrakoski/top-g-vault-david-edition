*Specifies the type of product information returned by [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService#GetProductInfoAsync|MarketplaceService:GetProductInfoAsync()]].*

## Description

Used to represent the possible information formats returnable by [[30 Official Roblox Docs/API Reference/Classes/MarketplaceService#GetProductInfoAsync|MarketplaceService:GetProductInfoAsync()]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Asset` | 0 | The product is an asset. |
| `Product` | 1 | Product such as a [[30 Official Roblox Docs/Production/Monetization/Developer Products\|Developer Product]]. |
| `GamePass` | 2 | The product is a game pass. |
| `Subscription` | 3 | The product is a subscription. |
| `Bundle` | 4 | The product is a bundle. |
