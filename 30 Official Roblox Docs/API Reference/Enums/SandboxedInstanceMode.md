*Controls whether sandboxed instance mode (script capabilities) is enabled.*

## Description

Determines whether sandboxed instance mode, which lets you use script capabilities, is active. This enum is used by [[30 Official Roblox Docs/API Reference/Classes/Workspace#SandboxedInstanceMode|Workspace.SandboxedInstanceMode]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Uses the engine-default sandboxed instance state. |
| `Experimental` | 1 | Sandboxed instance mode is enabled. |
