*Filters catalog search results by sales type.*

## Description

The [[30 Official Roblox Docs/API Reference/Enums/SalesTypeFilter|Enum.SalesTypeFilter]] enum is used with [[30 Official Roblox Docs/API Reference/Datatypes/CatalogSearchParams#SalesTypeFilter|CatalogSearchParams.SalesTypeFilter]] to filter catalog search results by their sales type when calling [[30 Official Roblox Docs/API Reference/Classes/AvatarEditorService#SearchCatalogAsync|AvatarEditorService:SearchCatalogAsync()]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `All` | 1 | Returns all items regardless of sales type. |
| `Collectibles` | 2 | Returns only collectible items (Limited and Limited Unique). |
| `Premium` | 3 | Returns only items with Premium pricing. |
| `TimedOptions` | 4 | Returns only items that have timed options available. |
