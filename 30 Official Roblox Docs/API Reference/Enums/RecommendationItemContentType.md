*Describes the content type of an item registered with [[30 Official Roblox Docs/API Reference/Classes/RecommendationService|RecommendationService]].*

## Description

This enum describes the content type of the recommendation item. It is designed to be generic.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Static` | 0 | The item is static, such as an image. |
| `Dynamic` | 1 | The item is dynamic; for example, it is a video. |
| `Interactive` | 2 | The item is interactive, such as a 3D model or a mini-game. |
