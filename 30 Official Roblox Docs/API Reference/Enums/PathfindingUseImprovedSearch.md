*Controls whether [[30 Official Roblox Docs/API Reference/Classes/PathfindingService|PathfindingService]] uses an improved search algorithm.*

## Description

Determines whether [[30 Official Roblox Docs/API Reference/Classes/PathfindingService|PathfindingService]] uses an improved pathfinding search algorithm. This enum is used by [[30 Official Roblox Docs/API Reference/Classes/Workspace#PathfindingUseImprovedSearch|Workspace.PathfindingUseImprovedSearch]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Uses the engine-default pathfinding behavior. |
| `Disabled` | 1 | Uses the legacy pathfinding search algorithm. |
| `Enabled` | 2 | Uses the improved pathfinding search algorithm. |
