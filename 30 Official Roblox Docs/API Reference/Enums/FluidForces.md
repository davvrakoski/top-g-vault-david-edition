*Controls the enablement of aerodynamic forces on parts and assemblies in the workspace.*

## Description

Used as an enum value for [[30 Official Roblox Docs/API Reference/Classes/Workspace#FluidForces|Workspace.FluidForces]] to control the enablement of aerodynamic forces on parts and assemblies in the workspace. Note that this enum is not applicable in scripting and [[30 Official Roblox Docs/API Reference/Classes/Workspace#FluidForces|Workspace.FluidForces]] must be toggled in Studio.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Aerodynamic forces will not be calculated on any [[30 Official Roblox Docs/API Reference/Classes/BasePart\|BaseParts]]. |
| `Experimental` | 1 | Aerodynamic forces will be calculated on [[30 Official Roblox Docs/API Reference/Classes/BasePart\|BaseParts]] with [[30 Official Roblox Docs/API Reference/Classes/BasePart#EnableFluidForces\|EnableFluidForces]] set to true. During the beta phase, the behavior of the aerodynamic force model may change as the model improves. |
