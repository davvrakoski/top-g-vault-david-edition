*BodyPartR15 is an enum with entries for each of the 15 body parts of an R15 character (plus an entry for the HumanoidRootPart).*

## Description

BodyPartR15 is an Enum used with both [[30 Official Roblox Docs/API Reference/Classes/Humanoid#GetBodyPartR15|Humanoid:GetBodyPartR15()]] and [[30 Official Roblox Docs/API Reference/Classes/Humanoid#ReplaceBodyPartR15|Humanoid:ReplaceBodyPartR15()]] to find and replace specific body parts of R15 characters.
