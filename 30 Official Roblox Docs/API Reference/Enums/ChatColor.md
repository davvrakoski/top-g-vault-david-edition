*Describes the chat color.*

## Description

The **ChatColor** enum is used to change the color of a chat using [[30 Official Roblox Docs/API Reference/Classes/Chat|Chat]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Blue` | 0 | The blue chat color; the default value passed to [[30 Official Roblox Docs/API Reference/Classes/Chat#Chat\|Chat()]] and `ChatLocal()`. |
| `Green` | 1 | The green chat color, passed as the `color` argument to [[30 Official Roblox Docs/API Reference/Classes/Chat#Chat\|Chat()]] or `ChatLocal()`. |
| `Red` | 2 | The red chat color, passed as the `color` argument to [[30 Official Roblox Docs/API Reference/Classes/Chat#Chat\|Chat()]] or `ChatLocal()`. |
| `White` | 3 | The white chat color, passed as the `color` argument to [[30 Official Roblox Docs/API Reference/Classes/Chat#Chat\|Chat()]] or `ChatLocal()`. |
