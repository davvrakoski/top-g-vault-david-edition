*Specifies the format of an ad used with [[30 Official Roblox Docs/API Reference/Classes/AdService|AdService]] methods.*

## Description

Specifies the format of an ad passed to [[30 Official Roblox Docs/API Reference/Classes/AdService|AdService]] methods such as [[30 Official Roblox Docs/API Reference/Classes/AdService#GetAdAvailabilityNowAsync|AdService:GetAdAvailabilityNowAsync()]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `RewardedVideo` | 0 | A full-screen video ad that plays to completion and rewards the viewer, used as the `adFormat` argument for [[30 Official Roblox Docs/API Reference/Classes/AdService\|AdService]] methods. |
