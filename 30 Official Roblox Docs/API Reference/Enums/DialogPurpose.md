## Description

The DialogPurpose enum is used to set the icon of a [[30 Official Roblox Docs/API Reference/Classes/Dialog|Dialog]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Quest` | 0 | Shows an exclamation point ('''!'''). |
| `Help` | 1 | Shows a question mark ('''?'''). |
| `Shop` | 2 | Shows a dollar sign ('''\$'''). |
