## Description

This enum is used with [[30 Official Roblox Docs/API Reference/Classes/DataModel#MatchmakingType|DataModel.MatchmakingType]] to represent how players in the server are handled by matchmaking.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 1 | Includes desktop, mobile, cross-play enabled players, etc. |
| `XboxOnly` | 2 | Xbox players with cross-play disabled. |
| `PlayStationOnly` | 3 | PlayStation players with cross-play disabled. |
