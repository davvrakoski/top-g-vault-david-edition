*Exposes the status of an immersive ad.*

## Description

Exposes the status of an immersive ad.

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Inactive` | 0 | The ad unit isn't currently serving an ad and it may be configured incorrectly. An [[30 Official Roblox Docs/API Reference/Classes/AdGui\|AdGui]] with this status will display its fallback image. |
| `Active` | 1 | The ad unit is currently serving an ad. Players will observe sponsored content in an [[30 Official Roblox Docs/API Reference/Classes/AdGui\|AdGui]] and an [[30 Official Roblox Docs/API Reference/Classes/AdPortal\|AdPortal]] will teleport users that walk through. |
