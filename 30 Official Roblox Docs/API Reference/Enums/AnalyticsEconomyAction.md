*Describes the type of economic transaction in [[30 Official Roblox Docs/API Reference/Classes/AnalyticsService#FireInGameEconomyEvent|AnalyticsService:FireInGameEconomyEvent()]].*

## Description

This enum is used as an argument in [[30 Official Roblox Docs/API Reference/Classes/AnalyticsService#FireInGameEconomyEvent|AnalyticsService:FireInGameEconomyEvent()]].

## Items

| Name | Value | Summary |
| --- | --- | --- |
| `Default` | 0 | Default action. Used for an undefined Action. |
| `Acquire` | 1 | Indicates the acquisition of an in game resource. For example, a player acquires virtual currency by completing a specific in game task. |
| `Spend` | 2 | Indicates the spending or loss of an in game resource. For example, a player spends virtual currency to acquire a new item. |
