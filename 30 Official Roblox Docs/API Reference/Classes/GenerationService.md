*Service that allows developers to generate 3D objects from text prompts.*

- **Inherits:** [[30 Official Roblox Docs/API Reference/Classes/Instance|Instance]] → [[30 Official Roblox Docs/API Reference/Classes/Object|Object]]
- **Memory category:** Instances
- **Tags:** `NotCreatable`, `Service`

## Description

`GenerationService` enables you to generate 3D objects from text prompts using Roblox's Cube 3D foundation model. This enables the generation of objects like environmental props in-experience, as well as fully functional models like vehicles that drive, planes that fly, and weapons that shoot.

## Methods

### GenerateMeshAsync

> [!warning] Deprecated
> This method is scheduled for future deprecation. Explore
> `Class.GenerationService:GenerateModelAsync()|GenerateModelAsync()` as a
> newer method.

```lua
GenerationService:GenerateMeshAsync(inputs: Dictionary, player: Player, options: Dictionary, intermediateResultCallback: Function?): Tuple
```

**Thread safety:** Unsafe · **Capabilities:** DynamicGeneration · **Tags:** `Yields`

Starts the generation of a new 3D mesh from a text prompt and returns unique IDs used to track and retrieve the result. Must be called from server scripts. You can optionally receive intermediate results, such as the untextured mesh, by providing an `intermediateResultCallback` function.

After the generation is complete, use [[30 Official Roblox Docs/API Reference/Classes/GenerationService#LoadGeneratedMeshAsync|LoadGeneratedMeshAsync()]] to load and display the generated mesh.

#### Error Codes

| Error                                      | Description                                                              | Recommended action                                                                   |
| ------------------------------------------ | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| Rate limit exceeded                        | The maximum number of mesh generations has been exceeded for the minute. | Wait until the rate limit resets.                                                    |
| Moderation failed                          | The mesh generation was flagged for moderation.                          | Review and modify the prompt to ensure it adheres to Roblox's moderation guidelines. |
| Internal server error                      | An unexpected issue occurred on the server.                              | Retry the request later or check server status for issues.                           |
| Character limit exceeded                   | The input prompt length for this generation request exceeded the limit.  | Reduce the number of characters in the `Prompt` string of the `input` dictionary.    |
| Service overloaded                         | The service is overloaded.                                               | Retry the request later.                                                             |
| Size dimensions must all be greater than 0 | Invalid size provided.                                                   | Change the size to above `0`.                                                        |

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `inputs` | Dictionary |  | A dictionary containing the mesh generation prompts. Currently, the only supported key is the `Prompt` (string) that describes the mesh to generate. |
| `player` | [[30 Official Roblox Docs/API Reference/Classes/Player\|Player]] |  | The [[30 Official Roblox Docs/API Reference/Classes/Player\|Player]] requesting the generation. |
| `options` | Dictionary |  | A dictionary for additional generation options to influence the result. The optional `SuggestedSize` key ([[30 Official Roblox Docs/API Reference/Datatypes/Vector3\|Vector3]]) represents a size guide for the generated asset, meaning `GenerationService` will attempt to create a model with a size and proportion similar to the provided [[30 Official Roblox Docs/API Reference/Datatypes/Vector3\|Vector3]], although there is no guarantee on the final output size. |
| `intermediateResultCallback` | Function? |  | A callback function triggered with intermediate generation results. Useful for retrieving early mesh versions before textures are applied. |

**Returns**

| Type | Description |
| --- | --- |
| Tuple | A tuple of the generation ID (a unique ID returned for each invocation of `GenerateMeshAsync()`) and context ID (not currently used). |

### GenerateModelAsync

```lua
GenerationService:GenerateModelAsync(inputs: Dictionary, schema: Dictionary, options: Dictionary?): Tuple
```

**Thread safety:** Unsafe · **Capabilities:** DynamicGeneration · **Tags:** `Yields`

Enables generation of multi-mesh geometries according to provided `inputs` and a `schema`.

Provide creative direction through `inputs`: a `TextPrompt`, an `Image` to condition on visually, or both. Control the output structure through `schema`, supplying either a built-in `PredefinedSchema` or a custom `SchemaDefinition` that names the parts to produce.

This method throws an error during the generation process for issues like prompt rejection, generation timeouts, `schema` mismatches, or backend service errors. It's recommended to wrap it in a [[30 Official Roblox Docs/API Reference/Globals/Luau globals#pcall|pcall()]] to catch such errors.

See [[30 Official Roblox Docs/Parts/Model generation|this guide]] for more detailed examples including usage of a `Behaviors` module to connect functional behaviors to generated models.

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `inputs` | Dictionary |  | A table representing conditioning inputs with the following keys:<br><br>- `TextPrompt` — String description of the object to generate. Required unless an `Image` is provided; you must supply at least one of `TextPrompt` or `Image`. - `Image` — Optional [[30 Official Roblox Docs/API Reference/Datatypes/Content\|Content]] referencing an image asset (for example, the result of [[30 Official Roblox Docs/API Reference/Datatypes/Content#fromAssetId\|Content.fromAssetId()]]) used to visually condition the generation. Supply it together with or instead of `TextPrompt`. - `Size` — Optional [[30 Official Roblox Docs/API Reference/Datatypes/Vector3\|Vector3]] describing the object size to generate. This is only approximate; scale the model extents post‑generation if you need a specific size. - `MaxTriangles` — Optional integer describing the maximum number of triangles that the returned model will contain. Lower values result in more faceted and low-poly generations. - `GenerateTextures` — `true` (default) textures the resulting generation, while `false` will not generate textures. |
| `schema` | Dictionary |  | Table representing the generation schema. Provide exactly one of the following keys:<br><br>- `PredefinedSchema` — String selecting a built-in schema. Current valid options are `Car5` for a basic vehicle chassis consisting of five [[30 Official Roblox Docs/API Reference/Classes/Model\|Models]], or `Body1` which results in a single mesh output. - `SchemaDefinition` — Table describing a custom multi-part structure. It contains a `Groups` array of part-name strings (one entry per desired part); the returned [[30 Official Roblox Docs/API Reference/Classes/Model\|Model]] is organized to match the named groups. Use this instead of `PredefinedSchema` when you need a structure the predefined schemas don't cover. |
| `options` | Dictionary? |  | Currently not used; reserved for future customization options. |

**Returns**

| Type | Description |
| --- | --- |
| Tuple | Tuple with the following elements:<br><br>- A standard [[30 Official Roblox Docs/API Reference/Classes/Model\|Model]] container instance that is compliant with the specified `schema`. - A table containing a UUID and other metadata about the generation. |

*Code samples for this member (`GenerationService-Basic-Car5`, `GenerationService-Custom-Schema`, `GenerationService-Image-Conditioning`) are published on the source page; their code is not part of the open-source repo.*

### LoadGeneratedMeshAsync

```lua
GenerationService:LoadGeneratedMeshAsync(generationId: string): MeshPart
```

**Thread safety:** Unsafe · **Capabilities:** DynamicGeneration · **Tags:** `Yields`

Retrieves and loads a mesh generated by [[30 Official Roblox Docs/API Reference/Classes/GenerationService#GenerateMeshAsync|GenerateMeshAsync()]] using the provided `generationId`. Must be called from client scripts.

The mesh can be returned as a [[30 Official Roblox Docs/API Reference/Classes/MeshPart|MeshPart]] or [[30 Official Roblox Docs/API Reference/Classes/Model|Model]]. Because editable meshes are not replicated, the loaded mesh is not replicated to any other clients and can only be loaded once per `generationId`.

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `generationId` | string |  | The unique ID returned by [[30 Official Roblox Docs/API Reference/Classes/GenerationService#GenerateMeshAsync\|GenerateMeshAsync()]]. Identifies the mesh to load. |

**Returns**

| Type | Description |
| --- | --- |
| [[30 Official Roblox Docs/API Reference/Classes/MeshPart\|MeshPart]] | The generated asset, returned as a [[30 Official Roblox Docs/API Reference/Classes/Model\|Model]] with a single [[30 Official Roblox Docs/API Reference/Classes/MeshPart\|MeshPart]] containing an [[30 Official Roblox Docs/API Reference/Classes/EditableMesh\|EditableMesh]]. |

### SegmentMeshAsync

```lua
GenerationService:SegmentMeshAsync(meshPart: MeshPart, schema: Dictionary, options: Dictionary?): Tuple
```

**Thread safety:** Unsafe · **Capabilities:** DynamicGeneration · **Tags:** `Yields`

Segments an existing [[30 Official Roblox Docs/API Reference/Classes/MeshPart|MeshPart]] into multiple named parts according to a provided schema and returns a [[30 Official Roblox Docs/API Reference/Classes/Model|Model]] with the segmented parts organized by the schema groups.

The `schema` parameter accepts the same structure as [[30 Official Roblox Docs/API Reference/Classes/GenerationService#GenerateModelAsync|GenerateModelAsync()]]: either a `PredefinedSchema` string (such as `"Car5"` for a five-part vehicle chassis or `"Body1"` for a single-mesh output) or a `SchemaDefinition` table with a `Groups` array of custom part names.

This method can only be called from Roblox Studio (edit mode or plugin context). For published mesh assets, the caller must have edit permission for the asset. Wrap calls in [[30 Official Roblox Docs/API Reference/Globals/Luau globals#pcall|pcall()]] to handle errors such as permission failures or mesh export issues.

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `meshPart` | [[30 Official Roblox Docs/API Reference/Classes/MeshPart\|MeshPart]] |  | The [[30 Official Roblox Docs/API Reference/Classes/MeshPart\|MeshPart]] to segment. Must contain mesh geometry (either an [[30 Official Roblox Docs/API Reference/Classes/EditableMesh\|EditableMesh]] or a published mesh asset the caller has edit permission for). |
| `schema` | Dictionary |  | A table specifying how to segment the mesh. Provide exactly one of `PredefinedSchema` (a string such as `"Car5"` or `"Body1"`) or `SchemaDefinition` (a table with a `Groups` array of part-name strings defining the segmentation structure). |
| `options` | Dictionary? |  | Has no effect. |

**Returns**

| Type | Description |
| --- | --- |
| Tuple | A tuple containing a [[30 Official Roblox Docs/API Reference/Classes/Model\|Model]] whose children are organized according to the specified schema (each group as a child [[30 Official Roblox Docs/API Reference/Classes/Model\|Model]] with a [[30 Official Roblox Docs/API Reference/Classes/MeshPart\|MeshPart]] inside), and a table with a `UUID` key holding the backend job identifier. |
