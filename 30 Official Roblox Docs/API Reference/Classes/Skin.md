## Description

The Skin object, when placed into a humanoid model, will change the colors all body parts of the torso, head, etc, to value of the [[30 Official Roblox Docs/API Reference/Classes/Skin#SkinColor|Skin.SkinColor]] property.

Superseded by the [[30 Official Roblox Docs/API Reference/Classes/BodyColors|BodyColors]] class.
