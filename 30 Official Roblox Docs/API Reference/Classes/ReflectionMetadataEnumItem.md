## Description

The ReflectionMetadataEnumItem is the class containing information about a specific EnumItem embedded within an Enum and should be parented to a [[30 Official Roblox Docs/API Reference/Classes/ReflectionMetadataEnum|ReflectionMetadataEnum]].

Since it is an internal object, it cannot be used by developers.
