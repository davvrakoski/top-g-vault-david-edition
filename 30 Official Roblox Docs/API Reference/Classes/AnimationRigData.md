- **Inherits:** [[30 Official Roblox Docs/API Reference/Classes/Instance|Instance]] → [[30 Official Roblox Docs/API Reference/Classes/Object|Object]]
- **Memory category:** Instances

## Description

An AnimationRigData instance commonly appears in the Data Model as a child of an AnimationClip. It is used to store information regarding the source rig an animation was authored for. It is currently only used for AnimationClips authored on [[30 Official Roblox Docs/Avatar/Character Bodies/Character body specifications#Rigging|R15 rigs]].
