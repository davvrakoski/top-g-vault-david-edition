- **Inherits:** [[30 Official Roblox Docs/API Reference/Classes/Instance|Instance]] → [[30 Official Roblox Docs/API Reference/Classes/Object|Object]]
- **Memory category:** Instances

## Description

Represents a single value published by an [[30 Official Roblox Docs/API Reference/Classes/AnimationValueNodeDefinition|AnimationValueNodeDefinition]], parented to the value node that produces it. It carries no data of its own; other nodes in the graph consume the value by pointing an [[30 Official Roblox Docs/API Reference/Classes/ObjectValue|ObjectValue]] wire at this instance.
