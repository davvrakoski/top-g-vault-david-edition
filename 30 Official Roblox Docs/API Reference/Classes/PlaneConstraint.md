## Description

A **PlaneConstraint** moves its [[30 Official Roblox Docs/API Reference/Classes/Constraint#Attachment0|Attachment0]] and [[30 Official Roblox Docs/API Reference/Classes/Constraint#Attachment1|Attachment1]] into a position/orientation along a plane whose normal vector is the primary axis of [[30 Official Roblox Docs/API Reference/Classes/Constraint#Attachment0|Attachment0]]. Both parent assemblies remain free to translate and rotate unless otherwise constrained.
