## Description

A special type of [[30 Official Roblox Docs/API Reference/Classes/Pages|Pages]] object whose pages contain key-value pairs from a [[30 Official Roblox Docs/API Reference/Classes/MemoryStoreHashMap|MemoryStoreHashMap]]. [[30 Official Roblox Docs/API Reference/Classes/Pages#GetCurrentPage|Pages:GetCurrentPage()]] can be used to retrieve an array of tables, each containing a key and value; these reflect the key-value pair data.

*Code samples for this API (`listing-data-hash-map-memory-store`) are published on the [source page](https://create.roblox.com/docs/reference/engine/classes/MemoryStoreHashMapPages); their code is not part of the open-source repo.*
