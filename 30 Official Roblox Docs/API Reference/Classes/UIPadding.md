## Description

[[30 Official Roblox Docs/API Reference/Classes/UIPadding|UIPadding]] applies padding to the borders of the parent [[30 Official Roblox Docs/API Reference/Classes/GuiObject|GuiObject]], either as a pixel amount ([[30 Official Roblox Docs/API Reference/Datatypes/UDim#Offset|Offset]]) or percentage of the parent's size ([[30 Official Roblox Docs/API Reference/Datatypes/UDim#Scale|Scale]]).
