## Description

The `OutfitPages` class is used in the case of iterating over a user's outfits. It's a special version of the [[30 Official Roblox Docs/API Reference/Classes/Pages|Pages]] class returned by [[30 Official Roblox Docs/API Reference/Classes/AvatarEditorService#GetOutfitsAsync|AvatarEditorService:GetOutfitsAsync()]].
