## Description

A **UnionOperation** is the result of individual parts that have been joined together into a single solid model through Studio's solid modeling **Union** tool, or through [[30 Official Roblox Docs/API Reference/Classes/BasePart#UnionAsync|BasePart:UnionAsync()]] or [[30 Official Roblox Docs/API Reference/Classes/BasePart#SubtractAsync|BasePart:SubtractAsync()]].

See [[30 Official Roblox Docs/Parts/Solid modeling|Solid Modeling]] to learn more about Studio's solid modeling tools and methods.
