## Description

A Hole is an unused type of surface joint. It can be connected to a [[30 Official Roblox Docs/API Reference/Classes/MotorFeature|MotorFeature]] object by using a [[30 Official Roblox Docs/API Reference/Classes/VelocityMotor|VelocityMotor]].
