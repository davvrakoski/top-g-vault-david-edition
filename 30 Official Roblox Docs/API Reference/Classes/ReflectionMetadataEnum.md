## Description

The ReflectionMetadataEnum is the class that registers information about an Enum, and its EnumItems. It should be parented to [[30 Official Roblox Docs/API Reference/Classes/ReflectionMetadataEnums|ReflectionMetadataEnums]].

Since it is an internal object, it cannot be used by developers.
