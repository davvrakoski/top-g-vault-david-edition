- **Memory category:** Instances
- **Tags:** `NotCreatable`, `Service`, `NotReplicated`

## Description

PluginGuiService is a service that stores [[30 Official Roblox Docs/API Reference/Classes/PluginGui|PluginGui]] objects to be displayed in Roblox Studio. It only allows PluginGuis to be direct children of the service, and PluginGuis are not allowed to be parented anywhere besides the service.
