## Description

The SelectionLasso class is an abstract class of which the inheritors are able to be attached to an object of the [[30 Official Roblox Docs/API Reference/Classes/Humanoid|Humanoid]] class or the [[30 Official Roblox Docs/API Reference/Classes/BasePart|BasePart]] class. They can also be attached to a point in the tridimensional space indicated by a Vector3 value.
