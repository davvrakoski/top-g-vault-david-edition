## Description

A deprecated legacy accessory container. [[30 Official Roblox Docs/API Reference/Classes/Hat|Hat]] is effectively a deprecated alias for the same [[30 Official Roblox Docs/API Reference/Classes/Accoutrement|Accoutrement]] behavior used by accessories: it has no additional members beyond [[30 Official Roblox Docs/API Reference/Classes/Accoutrement|Accoutrement]], and Attachment-based positioning works on any limb (not only the head). Prefer [[30 Official Roblox Docs/API Reference/Classes/Accessory|Accessory]] for new work.

*Code samples for this API (`Hat1`) are published on the [source page](https://create.roblox.com/docs/reference/engine/classes/Hat); their code is not part of the open-source repo.*
