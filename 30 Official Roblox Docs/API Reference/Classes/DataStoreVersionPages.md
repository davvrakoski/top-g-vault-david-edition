## Description

A special type of [[30 Official Roblox Docs/API Reference/Classes/Pages|Pages]] object whose pages contain [[30 Official Roblox Docs/API Reference/Classes/DataStoreObjectVersionInfo|DataStoreObjectVersionInfo]] instances from a [[30 Official Roblox Docs/API Reference/Classes/GlobalDataStore|GlobalDataStore]]. [[30 Official Roblox Docs/API Reference/Classes/Pages#GetCurrentPage|Pages:GetCurrentPage()]] can be used to retrieve an array of the [[30 Official Roblox Docs/API Reference/Classes/DataStoreObjectVersionInfo|DataStoreObjectVersionInfo]] instances.
