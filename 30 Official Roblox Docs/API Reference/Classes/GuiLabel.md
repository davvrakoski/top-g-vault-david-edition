## Description

GuiLabel is an abstract class that inherits from [[30 Official Roblox Docs/API Reference/Classes/GuiObject|GuiObject]]. It is the base class for [[30 Official Roblox Docs/API Reference/Classes/ImageLabel|ImageLabel]] and [[30 Official Roblox Docs/API Reference/Classes/TextLabel|TextLabel]]. Unlike [[30 Official Roblox Docs/API Reference/Classes/GuiButton|GuiButton]], objects of this type will not register click events, but instead serve as non-interactive labels. It does not implement any further properties, events or methods.
