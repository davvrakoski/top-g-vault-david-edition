*Serializes and deserializes [[30 Official Roblox Docs/API Reference/Classes/Instance|instances]] to and from the `.rbxm` format.*

- **Inherits:** [[30 Official Roblox Docs/API Reference/Classes/Instance|Instance]] → [[30 Official Roblox Docs/API Reference/Classes/Object|Object]]
- **Memory category:** Instances
- **Tags:** `NotCreatable`, `Service`

## Description

[[30 Official Roblox Docs/API Reference/Classes/SerializationService|SerializationService]] converts [[30 Official Roblox Docs/API Reference/Classes/Instance|instances]] to and from the binary `.rbxm` model format. Call [[30 Official Roblox Docs/API Reference/Classes/SerializationService#SerializeInstancesAsync|SerializeInstancesAsync()]] to serialize a list of instances into a [[30 Official Roblox Docs/API Reference/Libraries/buffer|buffer]] of `.rbxm` content, and [[30 Official Roblox Docs/API Reference/Classes/SerializationService#DeserializeInstancesAsync|DeserializeInstancesAsync()]] to reconstruct instances from such a buffer.

Usable only from Studio plugins or Open Cloud Luau Execution Sessions. Attempting to serialize or deserialize non-creatable instances or services throws an error.

No stability contract is offered for the `.rbxm` format; its composition may change at any time. Content serialized by the engine can always be deserialized by the engine, but parsing engine-generated `.rbxm` with third-party tools, or deserializing `.rbxm` generated by other means, is at the user's own risk.

## Methods

### DeserializeInstancesAsync

```lua
SerializationService:DeserializeInstancesAsync(buffer: buffer): List<Instance>
```

**Thread safety:** Unsafe · **Capabilities:** PluginOrOpenCloud · **Tags:** `Yields`

Deserializes a [[30 Official Roblox Docs/API Reference/Libraries/buffer|buffer]] containing `.rbxm` content, returning a list of [[30 Official Roblox Docs/API Reference/Classes/Instance|instances]].

This API can only be called from Studio plugins or Open Cloud Luau Execution Sessions. If non-creatable instances or services are included in the content, an error is thrown.

No stability contract is offered for the `.rbxm` format and the composition of this data may change at any time. This API will faithfully parse `.rbxm` content that was serialized by the Roblox engine, including `.rbxm` files generated by Studio or via [[30 Official Roblox Docs/API Reference/Classes/SerializationService#SerializeInstancesAsync|SerializeInstancesAsync()]].

Although it is possible to use this API to deserialize `.rbxm` content generated by any other means, this is done at the user's own risk. The engine may fail to deserialize such content faithfully, or at all.

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `buffer` | buffer |  | A [[30 Official Roblox Docs/API Reference/Libraries/buffer\|buffer]] containing the `.rbxm` content to deserialize. |

**Returns**

| Type | Description |
| --- | --- |
| List<[[30 Official Roblox Docs/API Reference/Classes/Instance\|Instance]]> | A list of the [[30 Official Roblox Docs/API Reference/Classes/Instance\|instances]] reconstructed from the buffer's `.rbxm` content. |

### SerializeInstancesAsync

```lua
SerializationService:SerializeInstancesAsync(inputInstances: List<Instance>): buffer
```

**Thread safety:** Unsafe · **Capabilities:** PluginOrOpenCloud · **Tags:** `Yields`

Serializes a list of [[30 Official Roblox Docs/API Reference/Classes/Instance|instances]] to the `.rbxm` format, returning a [[30 Official Roblox Docs/API Reference/Libraries/buffer|buffer]] or `.rbxm` content.

This API can only be called from Studio plugins or Open Cloud Luau Execution Sessions. If non-creatable instances or services are included in the list of instances, an error is thrown.

No stability contract is offered for the `.rbxm` format and the composition of this data may change at any time. This API will serialize content according to the serialization behavior of the current engine version.

Although it is possible for other tools to parse `.rbxm` content, this is done at the user's own risk. The engine may still generate `.rbxm` content that 3rd-party tools fail to parse faithfully.

**Parameters**

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `inputInstances` | List<[[30 Official Roblox Docs/API Reference/Classes/Instance\|Instance]]> |  | The list of [[30 Official Roblox Docs/API Reference/Classes/Instance\|instances]] to serialize. |

**Returns**

| Type | Description |
| --- | --- |
| buffer | A [[30 Official Roblox Docs/API Reference/Libraries/buffer\|buffer]] containing the `.rbxm` content of the serialized instances. |
