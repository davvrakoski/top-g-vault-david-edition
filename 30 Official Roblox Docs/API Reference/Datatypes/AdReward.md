*A reward that can be granted to users upon watching rewarded video ads.*

## Description

The `AdReward` data type represents a reward that can be used to trigger a rewarded video ad to play on the client via [[30 Official Roblox Docs/API Reference/Classes/AdService#ShowRewardedVideoAdAsync|AdService:ShowRewardedVideoAdAsync()]].
