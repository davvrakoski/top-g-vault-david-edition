*A root access point of all [[30 Official Roblox Docs/API Reference/Datatypes/Enum|Enums]].*

## Description

The [[30 Official Roblox Docs/API Reference/Datatypes/Enums|Enums]] data type, more commonly known as [[30 Official Roblox Docs/API Reference/Datatypes/Enum|Enum]] by its global variable in Luau), acts as the root access point for all available enums on Roblox. All enums on Roblox are indexed via their name through this data type, and developers can also utilize the `GetEnums()` method to get a list of all enums on Roblox.
