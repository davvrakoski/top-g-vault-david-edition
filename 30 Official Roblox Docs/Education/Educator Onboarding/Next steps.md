**Congratulations**! You've completed the Roblox Educator training and are now ready to inspire a new generation through play. We've compiled a list of resources to help you on your journey.

## Classroom kit

To help get your classroom started, the Classroom Kit that includes resources like cheat sheets and customizable templates. The kit can be downloaded as a .ZIP file, or the files can be downloaded individually below.

[Download Classroom Kit](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/legacy/Roblox_Classroom_Kit.zip)

## Educator resources

The following resources include different handouts, templates, and guides to better facilitate a Roblox classroom.

| | |
| --- | --- |
| [Classroom setup guide](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/legacy/Handout_-_Getting_Ready.pdf) | A step-by-step guide to setting up a classroom such as where to get software and accounts. |
| [Roblox glossary](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/legacy/Handout_-_Roblox_Glossary.pdf) | Lists common words unique to Roblox, such as obby or Robux. |
| [Trust and safety brochure](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/legacy/Safety_education_brochure.pdf) | Outlines the educational benefits of Roblox and safety features, such as chat protections. |
| [Assessment handouts (.zip)](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/legacy/Roblox_Assessment_Handouts.zip) | Assessment with one knowledge-focused quiz and one project-based rubric. |
| [Roblox client cheatsheet](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/legacy/Handout_-_Roblox_Client_Quick_Start_Guide.pdf) | In-depth reference for the Roblox Client controls, interface, and common concepts in Roblox games. |

We've compiled some of our favorite games to showcase the best that Roblox has to offer. To see more, browse the [Learn and Explore](https://www.roblox.com/discover#/sortName/Curated_67) Sort.

#### Ocean Conservation Game

A museum built in Roblox that educators people about ocean conservations.

[**Play**](https://www.roblox.com/games/6708164649/)

*(image in the full Top G Vault)*

#### Lua Learning

Learn how to code in Luau, the language used in all Roblox projects. The game is named Lua for historical reasons, as Roblox used Lua before developing it into Luau.

[**Play**](https://www.roblox.com/games/1334669864/)
