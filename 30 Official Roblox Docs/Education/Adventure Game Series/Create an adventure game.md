*How to make a game in Roblox Studio. Learn to design and code an adventure game for Roblox as a beginner.*

### Series description

Create an adventure game where players explore a world to find items to harvest and sell. Perfect for those who have already have some familiarity with Roblox Studio and basic coding concepts up to if/then statements.

[Video: adventure-game-examplevideo.mp4](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/education/adventure-game-series/adventure-game-examplevideo.mp4)
