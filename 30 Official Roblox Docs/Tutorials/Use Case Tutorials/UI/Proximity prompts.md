*The process for creating an interactive prompt that triggers an action on user input.*

You can create interactive proximity prompts that appear when users approach objects in the 3D space, then trigger actions on user input.

[Video: PromptsShowcase.mp4](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/tutorials/proximity-prompts/PromptsShowcase.mp4)

This tutorial uses the [Dungeon Delve](https://www.roblox.com/games/6749940622/Dungeon-Delve-Learn) project as a showcase. To follow along, open it in Studio before proceeding.

*(image in the full Top G Vault)*

## Create a prompt

On-screen prompts are generated by a [[30 Official Roblox Docs/API Reference/Classes/ProximityPrompt|ProximityPrompt]] object parented to an [[30 Official Roblox Docs/API Reference/Classes/Attachment|Attachment]], [[30 Official Roblox Docs/API Reference/Classes/BasePart|BasePart]], or [[30 Official Roblox Docs/API Reference/Classes/Model|Model]].

1. Select the **PrisonDoor** model in the 3D view or from the **Explorer** (**Workspace** → **PromptObjects** → **PrisonDoor**).

   *(image in the full Top G Vault)*
   *(image in the full Top G Vault)*

2. Expand its tree and select the **Door** object.

   *(image in the full Top G Vault)*

3. Placing a prompt on an [[30 Official Roblox Docs/API Reference/Classes/Attachment|Attachment]] gives you more control on where the point of interaction occurs, versus placing it directly on the part/model. Insert a new **Attachment** and rename it to **PromptAttachment**.

   *(image in the full Top G Vault)*

4. Locate the new attachment's **Position** property and set it to **-2.25**, **-0.5**, -**0.5**. This will move it in front of the door's key hole.

   *(image in the full Top G Vault)*
   *(image in the full Top G Vault)*

5. Hover over **PromptAttachment** and insert a new **ProximityPrompt** object.

   *(image in the full Top G Vault)*

### Prompt appearance

Prompts consist of three primary elements, each of which can be controlled by the following properties:

*(image in the full Top G Vault)*

- **ObjectText** — An optional name for the object being interacted with.
- **ActionText** — An optional action name shown to the user.
- **KeyboardKeyCode** — The keyboard key which will trigger the prompt.
- **GamepadKeyCode** — The gamepad button which will trigger the prompt.

To customize the appearance of the prison door prompt, make the following changes:

1. In the **Properties** window, locate the **ObjectText** property and type in **Door**.

   *(image in the full Top G Vault)*

2. For the **ActionText** property, type in **Pick Lock**.

   *(image in the full Top G Vault)*

### Activation distance

Prompts appear when the user's **character** moves within the defined **MaxActivationDistance** range of the prompt object's parent.

*(image in the full Top G Vault)*

The default value works well in most cases, but you can push user interaction closer to the lock by changing **MaxActivationDistance** to **4**.

*(image in the full Top G Vault)*

### Hold duration

The **HoldDuration** property value determines how quickly the prompt's action is triggered, in seconds. Since this door must be picked to unlock it, change the **HoldDuration** property to **4**.

*(image in the full Top G Vault)*

[Video: HoldDuration.mp4](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/tutorials/proximity-prompts/HoldDuration.mp4)

## Implement an action

The best way to detect prompt events is through [[30 Official Roblox Docs/API Reference/Classes/ProximityPromptService|ProximityPromptService]] — this lets you detect events centrally without attaching a script to each prompt object.

A basic framework is as follows:

```lua
local ProximityPromptService = game:GetService("ProximityPromptService")

-- Detect when prompt is triggered
local function onPromptTriggered(promptObject, player)

end

-- Detect when prompt hold begins
local function onPromptHoldBegan(promptObject, player)

end

-- Detect when prompt hold ends
local function onPromptHoldEnded(promptObject, player)

end

-- Connect prompt events to handling functions
ProximityPromptService.PromptTriggered:Connect(onPromptTriggered)
ProximityPromptService.PromptButtonHoldBegan:Connect(onPromptHoldBegan)
ProximityPromptService.PromptButtonHoldEnded:Connect(onPromptHoldEnded)
```

| Event | Description |
| --- | --- |
| [[30 Official Roblox Docs/API Reference/Classes/ProximityPromptService#PromptTriggered\|PromptTriggered]] | Fires when a user interacts with a prompt (**after** the duration for a prompt with non-zero [[30 Official Roblox Docs/API Reference/Classes/ProximityPrompt#HoldDuration\|HoldDuration]]). |
| [[30 Official Roblox Docs/API Reference/Classes/ProximityPromptService#PromptButtonHoldBegan\|PromptButtonHoldBegan]] | Fires when a user begins interacting with a prompt of non-zero [[30 Official Roblox Docs/API Reference/Classes/ProximityPrompt#HoldDuration\|HoldDuration]]. |
| [[30 Official Roblox Docs/API Reference/Classes/ProximityPromptService#PromptButtonHoldEnded\|PromptButtonHoldEnded]] | Fires when a user stops interacting with a prompt of non-zero [[30 Official Roblox Docs/API Reference/Classes/ProximityPrompt#HoldDuration\|HoldDuration]] |

In the [Dungeon Delve](https://www.roblox.com/games/6749940622/Dungeon-Delve-Learn) project, these events are managed by the **PromptEvents** script within **ServerScriptService**.

*(image in the full Top G Vault)*

Inside the script, the events above simply call functions within the **ObjectActions** [[30 Official Roblox Docs/API Reference/Classes/ModuleScript|ModuleScript]], also located in **ServerScriptService**.

```lua
local ProximityPromptService = game:GetService("ProximityPromptService")
local ServerScriptService = game:GetService("ServerScriptService")

local ObjectActions = require(ServerScriptService.ObjectActions)

-- Detect when prompt is triggered
local function onPromptTriggered(promptObject, player)
	ObjectActions.promptTriggeredActions(promptObject, player)
end

-- Detect when prompt hold begins
local function onPromptHoldBegan(promptObject, player)
	ObjectActions.promptHoldBeganActions(promptObject, player)
end

-- Detect when prompt hold ends
local function onPromptHoldEnded(promptObject, player)
	ObjectActions.promptHoldEndedActions(promptObject, player)
end

-- Connect prompt events to handling functions
ProximityPromptService.PromptTriggered:Connect(onPromptTriggered)
ProximityPromptService.PromptButtonHoldBegan:Connect(onPromptHoldBegan)
ProximityPromptService.PromptButtonHoldEnded:Connect(onPromptHoldEnded)
```

Proximity prompts are a convenient and customizable solution for in-game object interaction. Check out the [[30 Official Roblox Docs/API Reference/Classes/ProximityPrompt|ProximityPrompt]] and [[30 Official Roblox Docs/API Reference/Classes/ProximityPromptService|ProximityPromptService]] reference pages for even more ways to control prompt behavior, and explore other interactive objects in [Dungeon Delve](https://www.roblox.com/games/6749940622/Dungeon-Delve-Learn) for creative inspiration.
