*Learn the basics of creating an account, downloading Studio, and navigating its UI.*

*(image in the full Top G Vault)*

This tutorial acts as an introduction to Roblox Studio, a free application on Windows or Mac that has everything you need to start creating games on the Roblox platform! As you follow each chapter, you will learn how to login into Studio, then navigate its core user interface windows.

This lesson is intended for readers who are **brand new** to working in Studio. If you are already familiar with Studio, try another beginner lesson plan or jump straight to [[30 Official Roblox Docs/Tutorials/Curriculums/Core/Core curriculum|building your first game]].

## Course contents

   > [!note]- Chapter 1 - Create Roblox account
   > Learn how to [[30 Official Roblox Docs/Tutorials/Curriculums/Studio/Create Roblox account|create a free account]] on Roblox so that you can login to Studio.

   > [!note]- Chapter 2 - Install Roblox Studio
   > Learn how to [[30 Official Roblox Docs/Tutorials/Curriculums/Studio/Install Roblox Studio|install Studio]] on your computer.

   > [!note]- Chapter 3 - Explore Studio UI
   > Learn about the [[30 Official Roblox Docs/Tutorials/Curriculums/Studio/Explore Studio UI|fundamental windows]] you need to know to navigate Studio.

   > [!note]- Chapter 4 - Next steps
   > Learn where you can [[30 Official Roblox Docs/Tutorials/Curriculums/Studio/Next steps|find more tutorials]] about creating games.
