*Explains ways to continue learning about creating in Studio.*

Congratulations on completing your introduction to Roblox Studio! Now that you have Studio on your computer, login credentials, and familiarity with Studio's core user interface, you are ready to start building anything you can imagine.

## New to development?

If you are brand new to development, check out the following beginner tutorials on different development areas that you can specialize in:

- [[30 Official Roblox Docs/Tutorials/Curriculums/Building/Intro to building|Building lesson]] — Learn how to **build a simple platformer** using one of Studio's templates.
- [[30 Official Roblox Docs/Tutorials/Curriculums/Coding/Intro to coding|Coding lesson]] — Learn how to **code an interactive story** where players replace placeholder words with their own answers.
- [[30 Official Roblox Docs/Tutorials/Curriculums/Artist/Intro to VFX art|VFX lesson]] — Learn how to **customize special effects art** for a pre-made carnival ride game.
- [[30 Official Roblox Docs/Tutorials/Curriculums/Animator/Intro to animation|Animation lesson]] — Learn how to **create keyframes for various poses**, then loop them into a swimming animation that you can reuse in any game.

After you complete each of these tutorials, you will be ready to [[30 Official Roblox Docs/Tutorials/Curriculums/Core/Core curriculum|create your first game]] and learn about [[30 Official Roblox Docs/Tutorials/Fundamentals/Coding 1/Variables and objects|coding fundamentals]] for Luau, Studio's programming language.

> [!info]
> Game development is a massive field with a lot of different specializations. If one development area doesn't interest you, try another!

## Just new to Studio?

If you aren't new to development, but are new to Studio, check out the following guides for an overview of how games technically work:

- [[30 Official Roblox Docs/Projects/Projects|Projects]] — Learn how to create and manage projects in Studio.
- [Assets](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/index.md) — Learn about how everything in Roblox is represented as a cloud-based asset.
- [[30 Official Roblox Docs/Projects/Data model|Data model]] — Learn how places look and function in your games.
- [[30 Official Roblox Docs/Projects/Client-server runtime|Client-server runtime]] — Learn how games run in the Cloud.

After you have a solid understanding of these guides, you will be ready to examine the [[30 Official Roblox Docs/Resources/Plant reference project|Plant]] reference project that focuses on common use cases that you might encounter when you develop a game on Roblox, including tradeoffs, compromises, and the rationale of various implementation choices so that you can make the best decisions for your own games.

As you start to build your own games, be sure to check out the intermediate tutorials for common use cases, such as:

- [[30 Official Roblox Docs/Tutorials/Use Case Tutorials/UI/Create HUD meters|Create HUD meters]]
- [[30 Official Roblox Docs/Tutorials/Use Case Tutorials/Audio/Add 3D audio|Add 3D audio]]
- [[30 Official Roblox Docs/Tutorials/Use Case Tutorials/Data Storage/Save player data with standard data stores|Save player data]]

When you reach a point where you feel comfortable developing in Studio, you will be ready for the advanced paths that offer a deep dive into industry-standard workflows for areas like [[30 Official Roblox Docs/Tutorials/Curriculums/Environmental Art/Environmental art curriculum|environmental art]], [[30 Official Roblox Docs/Tutorials/Curriculums/Gameplay Scripting/Gameplay scripting curriculum|gameplay scripting]], and [[30 Official Roblox Docs/Tutorials/Curriculums/User Interface Design/User interface design curriculum|UI design]].
