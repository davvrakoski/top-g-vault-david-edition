*Learn best practices for creating user interfaces, including displaying critical information and implementing an art style.*

![](https://www.youtube.com/watch?v=eqW9SINYeWg)

**User Interface Design** is the discipline of planning and implementing UI elements that either provide essential information for gameplay, or teach players how to complete unique user flows within your games.

You'll learn how to recreate high-quality UI elements for a first-person shooter laser tag game by following step-by-step processes and best practices for following an art style, wireframing the structure and flow of UI information, and implementing UI designs within Studio.

This course is intended for readers who are familiar
with general building concepts and tools in Roblox Studio. If you need help
learning how to build an environment and navigating Studio's UI, try the [[30 Official Roblox Docs/Tutorials/Curriculums/Core/Core curriculum|core curriculum]].

## Course contents

   > [!note]- Chapter 1 - Choose an art style
   > Learn how to [[30 Official Roblox Docs/Tutorials/Curriculums/User Interface Design/Choose an art style|plan an aesthetic direction]] for your UI elements.

   > [!note]- Chapter 2 - Wireframe your layouts
   > Learn how to [[30 Official Roblox Docs/Tutorials/Curriculums/User Interface Design/Wireframe your layouts|design the structure and flow]] of the information you want to communicate through in various workflows.

   > [!note]- Chapter 3 - Implement designs in Studio
   > Learn how to [[30 Official Roblox Docs/Tutorials/Curriculums/User Interface Design/Implement designs in Studio|implement your UI layouts]] in Studio using both built-in and custom UI elements with scripts.
