*Explore the rendering budgets, reusable art, visibility, coins, and pets behind Cardboard Box Simulator.*

Learn from Peter "MrChickenRocket" McNeill's Cardboard Box Simulator performance
case study. This creator journal covers rendering budgets, reusable art,
visibility, distance culling, coins, pets, and effects, with four practical tasks
and six reference appendixes.

The measurements describe the author's 2024 project and test conditions. Use the
examples to establish and measure targets for your own experience.

Explore [Cardboard Box Simulator](https://www.roblox.com/games/17841214558/Cardboard-Box-Simulator)
and the [original article](https://devforum.roblox.com/t/real-world-building-and-scripting-optimization-for-roblox/3127146).
