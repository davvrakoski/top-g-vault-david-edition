*Data type having a value of either true or false.*

The **boolean** data type, or `bool`, has a value of either `true` or `false`.

## Conditionals

If a value isn't `false` or `nil`, Luau evaluates it as `true` in [[30 Official Roblox Docs/Luau/Control structures#If statements|conditional statements]]. Unlike many other languages, Luau considers both zero and the empty string as `true`.

## Operators

You can formulate complex conditions with [[30 Official Roblox Docs/Luau/Operators#Relational|relational]] and [[30 Official Roblox Docs/Luau/Operators#Logical|logical]] operators.
