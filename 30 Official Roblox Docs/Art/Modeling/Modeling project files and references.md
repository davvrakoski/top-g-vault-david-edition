*Download various modeling-related project files and reference files.*

The following `.fbx`, `.blend`, and `.ma` project files are available to use as templates or as reference:

Maple leaf tree

*(image in the full Top G Vault)*

A skinned tree model with the soil, branches, and leaves as separate meshes bound to a single armature. This is packaged with UV textures that can be applied with [[30 Official Roblox Docs/API Reference/Classes/SurfaceAppearance|SurfaceAppearance]]. This is an advanced version of the tree model used in the [[30 Official Roblox Docs/Art/Modeling/Skin a simple mesh|Skin a simple mesh]] guide.

[Download](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/skinned-meshes/MapleLeafTree_S3.zip)

Shoebot

*(image in the full Top G Vault)*

A robot non-player character used in the [Beyond The Dark](https://www.roblox.com/games/7208091524/Beyond-the-Dark-Vistech-Showcase) showcase.

[Download](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/shoebot-base-model.fbx)

Creature

*(image in the full Top G Vault)*

Creature model from the [Beyond The Dark](https://www.roblox.com/games/7208091524/Beyond-the-Dark-Vistech-Showcase) showcase. This model is made up of 11 meshes and over 50 bones.

[Download](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/skinned-meshes/CreatureModel.fbx)

## Avatar and accessories

The following include examples and templates utilizing Roblox's required [[30 Official Roblox Docs/Avatar/Character Bodies/Character bodies#Character body components|avatar components]]. Many of these project files and references require additional configuration in your modeling software before importing into Studio as a complete avatar character. See [[30 Official Roblox Docs/Avatar/Character Bodies/Character bodies|Character bodies]] for additional resources and template usage instruction.

*(image in the full Top G Vault)*

### Project files

R15 rig and attachments

*(image in the full Top G Vault)*

[[30 Official Roblox Docs/Avatar/Character Bodies/Character body specifications#Standard R15 rigs|Standard R15 rig]] template for Blender. Use this template for rigging **bodies** and **clothing** items.

[Download (.blend, .ma, .fbx)](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/Rig_and_Attachments_Templates.zip)

Cages for clothing

*(image in the full Top G Vault)*

Project files for creation, includes a full-body inner and outer cage mesh for creation of **clothing** items.

[Download (.blend, .ma, .fbx)](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/Clothing_Cage_Templates.zip)

Cages for bodies

*(image in the full Top G Vault)*

Project files for creation, includes the 15 individual body part cages required for caging your avatar **bodies**.

[Download (.blend, .ma, .fbx)](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/Body_Cage_Templates.zip)

Combined project files

*(image in the full Top G Vault)*

Template file containing all content from previous templates, includes rig skeleton, body cages, attachment points. <br> <br> Use this template to rig and cage bodies and clothing.

[Download (.blend, .ma, .fbx)](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/modeling/meshes/reference-files/Combined_Templates.zip)
