*Roblox provides template models to create your own unique avatar character in Blender.*

Each template comes pre-baked with the [[30 Official Roblox Docs/Avatar/Character Bodies/Character bodies#Character body components|necessary components of an avatar character body]] to save you time and effort in creating a custom avatar character. When creating character bodies from scratch, these individual components typically take a lot of time and a deep technical background in your modeling application. Templates allow you to skip several steps and work from a variety of base character body shapes.

You can choose from a variety of character body templates that best match your final design and save time on creating the technical components. The examples in the template tutorials utilize the [Round Blender template](https://github.com/Roblox/creator-docs/raw/main/content/en-us/assets/art/reference-files/RoundMale.zip). Experiment with other templates to create your own unique character and final result.

Each `.zip` contains a `.blend`, `.fbx`, and PBR texture `.png` files for that template model. If using Blender or following the [[30 Official Roblox Docs/Art/Characters/Creating/Create with templates|template creation guides]], use the `.blend` project.

> [!warning]
> Some of the template files include additional mesh assets for eyebrows and eyelashes. These eyebrows and eyelashes versions may not be fully compatible with the template body. For the latest information on eyebrows and eyelashes, see [[30 Official Roblox Docs/Avatar/Layered Accessories/Layered accessory specifications#Face accessories|Layered accessory specifications - Face accessories]].
