# 🚀 Fast Game Kit - Hub

> [!topg] Ship a Roblox game as fast as possible
> Drop in the starter place, pick a genre recipe, follow the day-by-day plan. Every step links the exact vault notes and FBX packs to use.

## The 3-step path

1. **Set up in 1 hour:** [[Starter Code - Hub]]. A Rojo starter place with data saving, currency, gamepasses and purchases, remotes, analytics, daily rewards, codes, shop UI and settings. Reskin it for every new game.
2. **Pick your game:** [[Genre Recipes - Hub]]. Simulator, tycoon, obby, arena shooter, battlegrounds, open-sea RPG, GTA-lite city, medieval RPG, horror. Each has an MVP list, build order, timeline, and the systems and assets to use.
3. **Follow the plan:** [[Playbook - Hub]]. The 30-day ship plan, a 7-day sprint, what to cut, the launch-week checklist and the AI-assisted workflow.

## Rules that keep you fast

- Build the **smallest fun version first**, then ship it, then update weekly.
- Use the vault's assets before making new ones: [[FBX Asset Library - Hub]].
- Reuse one starter place for every game. The second game takes days, not weeks.
- Stay inside Roblox policy: odds disclosure, honest thumbnails, no copied IP. See [[Asset Licenses and Credits]] for asset credits.
