# Visual Reference Production Atlas

This section converts visual references into **Roblox production knowledge**. The goal is not to copy a screenshot. The goal is to learn the construction logic behind it so you can build an original version that fits your own game, art direction and performance target.

## What the reference set teaches
The supplied studies cover five big production families:
1. stylized and realistic environment art,
2. layered real-time VFX,
3. hero creatures and tactical characters,
4. vehicle/surface interaction,
5. visual scalability from high-end presentation to Roblox-ready gameplay.

## Use this section in this order
1. [[Reference Decomposition Method — Turn Any Image Into a Build Plan|Reference Decomposition Method]]
2. choose the environment/VFX/character recipe closest to your goal,
3. build the smallest test scene,
4. use [[Visual Scalability and Quality Tiers|Visual Scalability & Quality Tiers]],
5. run [[Visual Production Master Checklist|Visual Production Master Checklist]],
6. profile on the lowest device you actually support.

## Important originality rule
Study **principles**: silhouette, composition, material response, particle timing, value structure, color hierarchy and technical layering. Do not rip meshes, textures, characters or exact copyrighted designs from reference art you do not own. See [[Reference IP, Originality and Asset Rights|Reference IP, Originality & Asset Rights]].
