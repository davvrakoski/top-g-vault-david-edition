# Production Labs

## Lab 1 — Secure shop
Client chooses item; server validates price, distance, funds, ownership.

## Lab 2 — 100 NPC stress test
Compare all-NPC Heartbeat logic vs. staggered distance-tier scheduler.

## Lab 3 — Streaming city
Build a large zone, enable streaming, fix every client assumption that breaks.

## Lab 4 — VFX cap
Spawn 100 impacts; build pooling/global cap/distance reduction.

## Lab 5 — Mobile UI
Take a desktop inventory and make it fully usable on narrow phone + gamepad.

## Lab 6 — Data failure
Simulate a save failure and verify the game does not silently claim success.

## Lab 7 — AI-generated asset cleanup
Generate a Tripo prop, audit topology/UV/scale, clean in Blender, import and profile.

## Lab 8 — Discovery experiment
Create two truthful thumbnail hypotheses and define the metric before running the test.
