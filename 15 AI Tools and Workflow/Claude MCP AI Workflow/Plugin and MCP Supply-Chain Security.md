# Plugin & MCP Supply-Chain Security

Plugins, packages, MCP servers and automation can save days — or receive dangerous access.

## Before installing
Check publisher/repository identity, source availability, license, recent maintenance, permissions, issue history and what network/filesystem access it needs.

## Least privilege
Do not give an AI integration access to production secrets, unrelated folders or destructive operations unless the task truly needs them.

## Test boundary
Use a disposable test experience/repository first. Keep a Git backup before allowing automated edits across many files.

## Red flags
- closed-source executable from an unknown account,
- instructions to disable security software,
- secret/API key pasted into public config,
- unexplained admin permissions,
- dependency that silently uploads project data.

## Lab
Create a one-page approval checklist for every tool your team installs.
