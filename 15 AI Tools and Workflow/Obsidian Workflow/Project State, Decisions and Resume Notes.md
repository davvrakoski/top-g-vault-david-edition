# Project State, Decisions & Resume Notes

Use different notes for different jobs.

PROJECT_STATE = current truth.
DECISIONS = why architecture choices were made.
RESUME_NOTE = what the next session needs immediately.
CHANGELOG = what changed over time.
BUGS = unresolved defects with reproduction evidence.

Keeping these separate saves AI context and prevents stale chat history from becoming the source of truth.

## Lab
End a session, start a new chat with only these files, and verify the AI can resume without re-explaining the entire project.
