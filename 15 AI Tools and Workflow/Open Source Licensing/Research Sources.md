Add:
- profiler screenshots
- before/after FPS data
- mobile device test results
- reusable modules you personally verified
- animation timing sheets
- texture/material standards
- thumbnail A/B test results
- retention lessons
- postmortems
- bugs that took hours to solve
- Roblox updates that changed old advice
- trusted GitHub repositories with license notes
- examples of bad AI output and how you fixed it

The strongest vault is not the one with the most words.
It is the one with VERIFIED knowledge, project-specific lessons, clear sources, and repeatable workflows.
