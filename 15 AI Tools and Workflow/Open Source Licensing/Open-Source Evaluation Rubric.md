# Open-Source Evaluation Rubric

Before importing a GitHub library:

## 1. License
Can you legally use/modify/distribute it?

## 2. Maintenance
- recent commits/releases?
- unresolved critical issues?
- archived repository?

## 3. Scope
Does it solve your problem, or add an entire framework for one tiny feature?

## 4. Security
- network calls?
- plugin permissions?
- arbitrary code loading?
- secrets?

## 5. Quality
- typed Luau?
- tests?
- docs?
- clear API?
- cleanup behavior?

## 6. Exit plan
Can you remove it later?

Never paste code because a YouTube video says "OP system." Read the source and license.
