# Reference IP, Originality & Asset Rights

A reference image can teach technique without granting permission to redistribute or copy the underlying asset.

## Safe mindset
Study:
- proportions,
- color relationships,
- lighting structure,
- material response,
- composition,
- VFX timing,
- technical construction.
Then create your own meshes, textures, characters and final design language.

## Do not assume
- a screenshot is free to redistribute,
- a Marketplace/portfolio image means the model is downloadable,
- a GitHub repo has a permissive license,
- an AI-generated remake automatically avoids copyright/trademark issues.

## Asset log
For every third-party asset record:
source, creator, URL, license, purchase proof if applicable, allowed commercial use, modification terms, attribution requirement, redistribution restriction.

## Public vault rule
If you cannot verify redistribution rights for a reference image, keep the vault's derived educational notes but do not bundle the original image.
