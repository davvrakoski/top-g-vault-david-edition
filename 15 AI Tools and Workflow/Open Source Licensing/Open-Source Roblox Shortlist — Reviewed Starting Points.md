# Open-Source Roblox Shortlist — Reviewed Starting Points

These are **starting points to evaluate**, not automatic requirements.

## Rojo
https://github.com/rojo-rbx/rojo
Professional filesystem/project sync tooling. MPL-2.0.

## Wally
https://github.com/UpliftGames/wally
Package manager for Roblox. Current README recommends Rokit for installation.

## StyLua
https://github.com/JohnnyMorganz/StyLua
Formatter with Luau support; active 2026 releases.

## Luau Language Server
https://github.com/JohnnyMorganz/luau-lsp
External-editor language server; active 2026 releases.

## selene
https://github.com/Kampfkarren/selene
Lua/Luau linter with Roblox support.

## RbxUtil
https://github.com/Sleitnick/RbxUtil
Collection of focused utilities including Trove, Signal, Timer, TypedRemote and more. Evaluate only the modules you need.

## NevermoreEngine
https://github.com/Quenty/NevermoreEngine
Large, actively developed library ecosystem with many reusable packages. Powerful but much larger in scope.

## Matter ECS
https://github.com/matter-ecs/matter
Modern ECS library. Best for developers who actually need data-oriented entity/system architecture.

## roblox-lua-promise
https://github.com/evaera/roblox-lua-promise
Promise implementation for structured async workflows.

## TestEZ
https://github.com/Roblox/testez
Historically important test framework, but the official repository is archived/read-only as of 2024. Treat it as a legacy option/reference and evaluate maintained alternatives before standardizing a new project on it.
