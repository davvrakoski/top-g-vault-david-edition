# Graph View Setup

The vault ships with a global graph configuration in `.obsidian/graph.json`.

## Open it
1. Extract the ZIP.
2. In Obsidian choose **Open folder as vault**.
3. Select the extracted `TDOD_ROBLOX_MASTER_VAULT_PREMIUM` folder.
4. Open **Graph view** from the left ribbon or Command Palette.
5. Give the force layout a moment to settle.

## What creates the clusters
- Every knowledge note has one `cluster/...` tag.
- Every note links to its cluster hub.
- Notes also link to related notes and neighboring clusters.
- `Top G Vault` links to every cluster hub.
- Graph color groups are based on the cluster tags.

## If the graph looks too crowded
Turn off **Attachments** and **Tags as nodes** (already disabled in the supplied config), reduce text visibility, or temporarily filter to one cluster such as:

`tag:#cluster/ai`

## If colors do not appear
Open Graph settings -> **Groups**. The included groups should be present. If Obsidian was already open while the vault files were replaced, close/reopen the graph or reload Obsidian so it reads the packaged configuration.
