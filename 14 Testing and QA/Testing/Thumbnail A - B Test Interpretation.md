# Thumbnail A/B Test Interpretation

A/B tests need a hypothesis. Change one major variable when possible and measure enough traffic before drawing conclusions.

Click-through without downstream engagement can indicate misleading imagery. Judge acquisition alongside first-session quality.

## Lab
For each variant write: hypothesis, changed variable, primary metric, guardrail metric and decision rule.
