# Definition of Done

A feature is not done because it works once.

A feature is done when:
- acceptance criteria pass
- failure states are handled
- remotes are validated/rate-limited where needed
- mobile/gamepad impact checked
- save compatibility checked if data changed
- profiler impact checked if system runs frequently
- cleanup/disconnect behavior verified
- analytics added if product decision depends on it
- documentation/resume note updated
- no known critical regression remains
