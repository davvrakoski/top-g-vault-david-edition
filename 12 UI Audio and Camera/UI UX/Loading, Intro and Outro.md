# LOADING, INTRO & OUTRO

=================================================

LOADING:
Keep ReplicatedFirst small.
Preload only essentials:
- loading UI
- main menu essentials
- spawn-area critical assets

Do NOT preload the entire Workspace.

LOADING SCREEN CONTENT:
- game logo
- progress state
- tips
- skip button for long optional preloads
- accessibility-friendly motion

INTRO:
Fast.
Skippable after first viewing when practical.
Do not force a 60-second logo sequence every session.

OUTRO:
Summarize reward.
Show progression.
Give next goal.
Make replay easy.

=================================================
