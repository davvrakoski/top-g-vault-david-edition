# UI Design System & Tokens

A polished game does not redesign every button independently.

## Tokens
Define spacing, corner radii, text sizes, font roles, panel opacity, stroke thickness and motion timing in one place.

## Components
Build reusable Button, Tab, Modal, Toast, ItemSlot, Meter and Tooltip components. States should include default, hover, pressed, selected, disabled and loading where relevant.

## Responsive rules
Combine scale with constraints and test very wide, tall and small screens. Important HUD should respect safe zones and touch controls.

## Motion
Use a small set of easing/timing patterns. Random animation styles make UI feel cheaper, not richer.

## Lab
Rebuild three different menus using the same component library. If each needs custom one-off styling, the design system is incomplete.
