# Modern Roblox Toolchain Menu

You do not need every tool.

**Studio only** — simplest, good for many projects.

**Studio + Script Sync + Git** — native external-editor/version-control workflow.

**Rojo + Git** — file-first project workflow with broader project sync/build options.

Useful optional tools:
- Luau Language Server: external-editor language intelligence
- StyLua: deterministic formatting
- selene: linting/static analysis
- Wally: Roblox package manager
- GitHub/GitLab/Bitbucket: hosted version control/code review

Evaluate tools by:
- active maintenance
- license
- security surface
- team familiarity
- migration cost
- whether it solves a real problem

Official Roblox now documents Script Sync and also names community tooling such as Luau LSP, selene, and StyLua as options for external-editor workflows.

Source: https://create.roblox.com/docs/projects/external-tools
