# UI / UX

=================================================

UI = what it looks like.
UX = how it works and feels.

GOOD UI:
- readable hierarchy
- consistent spacing
- consistent fonts
- clear states
- obvious focus/selection
- responds to controller/mobile
- not covering gameplay
- contrast
- motion with purpose
- fast menus
- scalable layout

UI HIERARCHY:
Primary action
Secondary action
Supporting info
Decoration

USE:
- anchors
- scale
- constraints/aspect ratio
- layout objects
- padding
- reusable components
- style tokens
- consistent corners/strokes
- safe areas

EYE CANDY UI WITHOUT "AI SLOP":
- fewer effects
- intentional spacing
- one visual theme
- restrained glow
- crisp icons
- coherent material language
- subtle motion
- strong typography
- avoid 15 gradients at once
- avoid random neon borders
- avoid fake tiny text
- avoid clutter

HUD:
Only show information needed during play.
Hide secondary data until relevant.
