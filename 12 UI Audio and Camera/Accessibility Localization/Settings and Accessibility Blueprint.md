# Settings and Accessibility Blueprint

Suggested settings:
- master/music/SFX volume
- mouse sensitivity
- gamepad sensitivity
- camera shake
- intense flashes
- subtitle toggle/size
- UI scale if supported
- hold/toggle behaviors
- performance preset if game adds custom effects

Client applies presentation settings immediately. Save stable settings to server DataStore if they should persist across devices.
