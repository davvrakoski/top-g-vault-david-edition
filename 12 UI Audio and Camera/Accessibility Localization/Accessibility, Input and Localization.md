# ACCESSIBILITY, INPUT & LOCALIZATION

=================================================

ROBLOX IS CROSS-PLATFORM.

Support:
- keyboard/mouse
- touch
- gamepad
- potentially VR if game targets it

INPUT ACTION SYSTEM:
Define actions such as:
Jump
Sprint
Attack
Interact
Inventory
Then bind per device.

ACCESSIBILITY OPTIONS:
- camera shake slider
- motion blur-like effects toggle if applicable
- flash intensity option
- subtitles
- text size
- colorblind-friendly signals
- hold vs toggle
- sensitivity
- volume categories

LOCALIZATION:
Do not bake critical text into images.
Use localization-ready UI.
Keep strings centralized where possible.
Allow UI to expand for longer translated text.
