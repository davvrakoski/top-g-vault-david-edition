# Characters Avatars and UGC - Sources Checked and Left Out

What was looked at for this cluster on 2026-10-25 and why it was not used or not bundled. Policy for this vault: only CC0, CC BY 4.0 or MIT material is bundle-safe; everything else is linked or summarized.

## Used as facts, not bundled as files

| Source | Why |
| --- | --- |
| Roblox Creator Hub docs | CC BY 4.0 (code samples MIT). Summarized in our own words and credited in every note. Mirrored copies live in `30 Official Roblox Docs`. |
| Roblox avatar project files (rig, cages, attachments, mannequins) | Official downloads, but no license is stated on the resources page in our check. Linked, not bundled. |
| DevForum threads | Forum posts have no open license. Used for symptoms and fixes, credited by username, no code copied. |

## Left out or reference only

| Source | Reason |
| --- | --- |
| *In Game Avatar Editor v2* (0_1195, 2021) | No license stated on the post, catalog database admitted out of date, pre-Async APIs. Mentioned as a study reference only. |
| *Free character Morph Script* (DevForum resource) | No license stated; pattern described, our own code written instead. |
| Third-party Blender cage add-on cages | A DevForum thread (topic 3222059) reported import errors with them while the official template imported cleanly. We recommend official cages only. |
| Secondary blogs on UGC fees (2026 news and guide sites) | Conflicting and unverified fee figures (one claimed a 2D upload fee change in July 2026). We used the Creator Hub fees page only. |
| Old UGC Program application posts (2019 to 2022) | Historical only; the application process was sunset. |
| reddit.com | Blocked for our tools; not used. |
