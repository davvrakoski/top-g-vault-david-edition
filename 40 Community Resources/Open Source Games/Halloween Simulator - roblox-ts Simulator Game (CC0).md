# Halloween Simulator - roblox-ts Simulator Game (CC0)

**Author:** MonzterDev · **License:** CC0-1.0 (public domain dedication) · **GitHub:** about 13 stars, 76 commits, last push 24 Oct 2022

## What it is
A learning-project simulator: collect candy, sell it, buy bigger baskets, hatch pet eggs and unlock areas. The author says it was never meant to ship and lists known flaws (rough UI, unfinished systems), but nearly every classic simulator system is present.

**Genre:** simulator (collect, sell, upgrade, pets).

## What you can reuse
- Currency, upgrade shop, unlockable areas, quests, settings and notifications.
- Pet and boost inventory, pet index and egg hatching.
- Game pass and developer product store, redeem codes, daily group reward and daily gifts.
- Because it is CC0 you can take any part with no attribution duty (a credit is still polite).

## How to run it
1. Clone the repo.
2. Open `Halloween Simulator.rbxl` in Studio. The place holds Workspace, ServerStorage and other content that is not in the source folders.
3. To edit code as TypeScript: install Node.js and Aftman, `aftman install`, `npm install`, `npx rbxtsc -w`, then `rojo serve` and connect the plugin.

## Caveats
- CC0 covers what the author owns. Models or audio inside the `.rbxl` that came from the Toolbox keep their original creators' terms; audit before you publish.
- Simulator monetization (eggs, boosts) must follow Roblox's paid random item rules; see [[Paid Random Items, Odds Disclosure and PolicyService]].
