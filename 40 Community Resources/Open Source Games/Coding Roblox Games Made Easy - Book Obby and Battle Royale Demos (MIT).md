# Coding Roblox Games Made Easy - Book Obby and Battle Royale Demos (MIT)

**Publisher:** Packt Publishing (book code for *Coding Roblox Games Made Easy*, 1st and 2nd editions) · **License:** MIT on both repos · **GitHub:** 1st edition about 61 stars, last push 30 Jan 2023; 2nd edition about 40 stars, last push 3 Jul 2024

## What it is
The companion code for a beginner book that builds two complete games: an **obby** with traps and rewards, and a **last-player-standing battle game** with weapons and a battlefield. The code is split into `Client` and `Server` folders per chapter.

**Genre:** obby and battle royale / arena (beginner level).

| Repo | Ready place files seen |
|---|---|
| 1st edition | `Chapter05/ObbyDemo.rbxl`, `Chapter06/BattleRoyaleDemo.rbxl` |
| 2nd edition | Chapter03 to Chapter07 code folders (Client and Server scripts); no place file shown in Chapter07 |

## What you can reuse
- The obby's trap and reward scripts as a first-obby base.
- The battle demo's match flow, weapons and last-player-standing logic for a small arena game.
- Very readable beginner Luau; good for teaching a new team member. Open the place files to see exactly which systems each chapter adds.

## How to run it
1. Clone or download the repo.
2. Open `Chapter05/ObbyDemo.rbxl` or `Chapter06/BattleRoyaleDemo.rbxl` (1st edition) in Studio and press Play.
3. For the 2nd edition, create a new place and paste the scripts from each chapter's `Server` folder into ServerScriptService and `Client` folder into StarterPlayerScripts, following the book.

## Caveats
- MIT covers the code in the repo. The book text and images are Packt's copyright, not open source.
- Code style predates some 2024-2026 APIs; test against current Studio.
