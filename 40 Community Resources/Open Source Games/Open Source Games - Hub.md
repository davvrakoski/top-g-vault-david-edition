# Open Source Games - Hub

Full games, game templates and sample places you are **allowed** to use as the base of your own Roblox game. Every entry was checked on its own page on 2026-10-25: the license file on GitHub, or Roblox's own statement for official places. Star counts and dates are as shown that day.

**Read first:** [[How to legally build on an open-source Roblox game]]

## Pick by goal
- **Fastest legal start:** [[Roblox Studio Templates - Official Uncopylocked Starter Games]] (Platformer, Laser Tag, Racing, Obby).
- **Study a real, big game:** [[Zombie Strike - Kampfkarren Co-op Zombie Shooter Source (MPL-2.0)]], [[Slither - roblox-ts Casual Snake Game (MIT)]].
- **Clean modern code base, no gameplay:** [[Roblox Game Boilerplate for AI Agents - Rojo, Wally, ProfileStore (Unlicense)]] (Luau) or [[Modern roblox-ts Template - Flamework Starter (Unlicense)]] (TypeScript).
- **Anti-cheat shooter movement:** [[Chickynoid - Server-Authoritative Character Controller with Demo Place (MIT)]].

## Checked and left out
These came up in searches but are **not** catalogued:
- **No license detected by GitHub on 2026-10-25** (no permission to reuse unless the author adds one): roblox-ts/demo-game, MonzterDev/Roblox-TS-Template, B-Ricey763/Roblox-Studio-Tycoon, A-Ricemusic/RPG-Template (README says free, but no license), jakierice/roblox-rpg-kit, Dekkonot/crossroads-rojo, knettia/BEYW, Blupo/ATDG, l0exy1h/Operation-Scorpion, elomala/Fighting-game.
- **License not detected / custom (NOASSERTION):** evilbocchi/eternal-empire, AsynchronousAI/chess-roblox.
- **GPL (whole-game copyleft):** cubacadabra/first-game and second-game, TheBoogle/Bagel-Arena.
- **Unclear origin of included code or assets:** GabrielNat1/blox-dutty-2021 (mixes uncredited tool code), pastadudes/colorando (much code taken from another game with no stated license), Astrophsica/Racing-Kit-Roblox (kit credit points to a different studio), CS460GraphBox/GraphBox (uses real people's likenesses).
- **Leaked material:** TheNexusAvenger/Roblox-The-Witching-Hour-Remastered (README says it used leaked models).
- **Not a game yet:** T-R-I-X/Jorik-TS (only data saving done).
- **Spam / exploit repos:** many 2026 "tycoon template" and "script hub" repos with SEO descriptions and no license; script dumps of other games. Never use them.
