# Slime Defense - 24-Hour Wally Demo Game (Apache-2.0)

**Author:** dig1t · **License:** Apache-2.0 · **GitHub:** 1 star, 5 commits, last push 7 Mar 2024, **archived** (read-only) on 25 Feb 2025 · **Full version:** roblox.com/games/109800116

## What it is
A demo game made for a 24-hour Roblox coding challenge. The repo ships both the Rojo source and a prebuilt `place.rbxl`. The page does not spell out the gameplay; the name points to a defense game, so open the place to confirm.

**Genre:** small defense / game-jam prototype.

## What you can reuse
- A compact example of a whole game built fast with Rojo + Wally, useful for game-jam teams.
- The prebuilt place as a quick look at how a 24-hour scope is cut.

## How to run it
1. Install Foreman, then `foreman install` (Rojo 7.2.1, Wally 0.3.1).
2. `wally install` (the README says the project requires Wally).
3. Either open `place.rbxl` in Studio, or `rojo serve` and connect the plugin.

## Caveats
- Archived: no fixes will come.
- Apache-2.0 covers the code; the page says nothing about the art in `place.rbxl`, so audit models and audio before you publish.
- Keep the LICENSE and mark files you change (Apache-2.0 section 4).
