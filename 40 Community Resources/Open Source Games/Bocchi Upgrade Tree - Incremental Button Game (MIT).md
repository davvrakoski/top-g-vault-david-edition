# Bocchi Upgrade Tree - Incremental Button Game (MIT)

**Author:** evilbocchi · **License:** MIT · **GitHub:** about 4 stars, 5 commits, last push 10 Jul 2025

## What it is
An inactive incremental (upgrade tree / button) game released for learning. The README invites people to use, modify or learn from the code.

**Genre:** incremental / idle upgrade game.

## What you can reuse
- Controller-per-system layout: `AreaController`, `ButtonController`, `CurrencyController`, split across client, server and shared folders.
- Button-press upgrade mechanics and currency flow for an upgrade-tree or button simulator.

## How to run it
1. Install Rokit, then `rokit install` (Rojo 7.5.1, Wally 0.3.2).
2. `wally install` for the `Packages/` folder.
3. Open the included `game.rbxl`, or `rojo serve` and connect the plugin.

## Caveats
- Unmaintained; small codebase.
- Wally packages keep their own licenses.
- The author's other repo, `eternal-empire`, has no clear license and is **not** included here.
