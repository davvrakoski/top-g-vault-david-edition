# Modern roblox-ts Template - Flamework Starter (Unlicense)

**Author:** HowManySmall · **License:** Unlicense (the LICENSE file is the public-domain Unlicense text; the README badge still says MIT, the file wins) · **GitHub:** about 15 stars, last push 4 Jun 2025

## What it is
A template repo for starting a Roblox game in TypeScript with roblox-ts and **Flamework** (services, controllers, components with dependency injection), using Bun as the package runner.

**Genre:** game template (any genre).

## What you can reuse
- The project skeleton and config.
- The README's curated package list by category (animation, data, React, state, utilities), with the author's own picks starred, for example ProfileService Plus or Lapis for data, Charm or Reflex for state, Iris for debug UI.

## How to run it
1. Install Bun.
2. Clone the repo (or "Use this template").
3. `bun install`
4. `bun run start` (compiles and serves; check `package.json` for the exact script), then connect the Rojo plugin in Studio.

## Caveats
- No gameplay; it is a starting shell.
- Each npm package you add keeps its own license.
