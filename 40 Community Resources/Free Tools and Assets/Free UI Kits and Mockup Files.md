# Free UI Kits and Mockup Files

Ready-made buttons, panels and sliders to start a menu quickly, plus where to find mockup files to plan UI before building it in Studio.

| Source | What | License | Credit? | Bundle-safe? | Link |
|---|---|---|---|---|---|
| **Kenney UI Pack** (v2.0, remade; ~430 files) | Buttons, panels, sliders, checkboxes in several colors | CC0 | No | **YES** (Kenney is already in [[Asset Licenses and Credits]]) | https://kenney.nl/assets/ui-pack |
| **Figma Community** free files | Thousands of UI kits and mockups, including game HUD and shop layouts | Free Community files are published under **CC BY 4.0** (Figma Help Center) | **Yes**, credit the file's creator | Only with credit recorded, and only if the file is clearly the uploader's own work | https://www.figma.com/community |
| **Creator Store UI assets** | UI models and images uploaded by Roblox creators | Roblox Terms | No | **Use-only** inside your Roblox game | Studio Toolbox |

## Using a kit well
- **9-slice everything** that stretches (panels, buttons) so one image fits every size: see [[UI 9-slice design]].
- Re-color the kit to your game's palette (white base + `ImageColor3`), so it doesn't look like every other Kenney-UI game.
- Build the kit once as reusable components, then style them from one place: [[UI Design System and Tokens]] and Studio's [[UI styling]].

## Figma Community caution
CC BY 4.0 only protects you if the uploader really made the file. Skip "Roblox UI kit" files that copy a famous game's shop or HUD, or that include Roblox logos and other brand art. Record creator name + file link for every Figma file you borrow from.
