# Free Tools and Assets - License Rules for This Folder

> **One-line rule:** "free to use" is not the same as "free to put in this vault". This vault is sold, so every table here has a **Bundle-safe?** column, and most rows say **No - link only**.

## How to read the tables

| Value | Meaning |
|---|---|
| **YES** | CC0, CC BY 4.0 (credit written down) or MIT / no-copyright. Files could be shipped inside the vault. Still check [[Asset Licenses and Credits]] for owner exclusions. |
| **Use-only** | You may use it inside your own Roblox game, but you may not hand the raw files to others (Sonniss, Pixabay, Creator Store audio, ShareTextures). |
| **No - link only** | Software, Studio plugins and anything with a custom, GPL, MPL, Apache, ISC or CC BY 3.0 license. Link to the official page; never copy the files into the vault. |

## Why Studio plugins are always "link only"
- Plugins live on the Roblox Creator Store. Roblox lets you distribute or sell only assets **you** created, so a plugin by someone else is never re-uploaded or bundled. Install it from its store page.
- "Free" on the store is shown by the asset being free to take (the Roblox asset API reports it as public domain / free). Paid plugins are sold in USD only, between $4.99 and $249.99, per the Creator Store docs.
- Every plugin table in this folder was checked against the Roblox asset details API on 2026-10-25 (name, creator, free or not, last update).

## Why free software does not taint your game
- Blender's license page says what you make with Blender is your own property, and you may use it commercially. Krita's license page says the same. GPL rules apply when you **redistribute the program**, not your art.
- Same idea for code tools (Rojo, Lune, darklua): using them on your project does not put your game under their license. Copying their **source** into your game does.

## Where Reddit fits
Reddit (r/robloxgamedev, r/ROBLOXStudio) was used for discovery only and was not fetchable on 2026-10-25, so most picks here were cross-checked through DevForum threads and the creators' own pages. Every license in this folder was read on the resource's own page or repository.

## Before you add anything new
1. Read the license on the creator's own page, not a blog or a re-upload.
2. Log it with [[Asset and License Log Template]].
3. If the license is unclear, leave it out and add it to [[Checked and Left Out - Free Tools and Assets]].
