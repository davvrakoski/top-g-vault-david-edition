# Free Sound Effect Sources - License Table

Where free SFX for Roblox games come from, and which ones are safe for what. Every license was read on the source's own page on 2026-10-25.

| Source | What | License | Credit? | Bundle-safe? | Link |
|---|---|---|---|---|---|
| **Kenney audio packs** (Interface Sounds, Impact Sounds, RPG Audio, UI Audio, Sci-fi Sounds, ...) | Clean game SFX (Interface Sounds alone has 100 files) | CC0 | No | **YES** (Kenney is already logged in [[Asset Licenses and Credits]]) | https://kenney.nl/assets/category:Audio |
| **Freesound** - CC0 sounds only | Huge community library | Per sound: CC0, CC BY 4.0, CC BY-NC 4.0 (older: Sampling+) | CC0 no; CC BY yes | CC0: **YES**; CC BY 4.0: **YES with credit**; BY-NC / Sampling+: **never** (games earn money) | https://freesound.org |
| **Sonniss #GameAudioGDC bundles** | Pro-quality libraries released yearly | Royalty-free; commercial use OK; no credit needed; **no redistributing the sounds as sounds**, no sample packs, no AI training | No | **Use-only** | https://sonniss.com/gdc-bundle-license/ |
| **Pixabay sound effects** | Stock SFX | Pixabay Content License: free use, no credit, **no standalone redistribution or sale** | No | **Use-only** | https://pixabay.com/service/license-summary/ |
| **OpenGameArt** | Mixed game assets | Per asset (CC0, CC BY, BY-SA, OGA-BY, GPL) | Depends | Only the CC0 ones; see [[More Free Sources - OpenGameArt CC0]] | https://opengameart.org |
| Your own recordings / [[Free SFX Generators - ChipTone and jsfxr]] | Original | Yours | No | **YES** | - |

## How to use each safely
- **Freesound:** filter by license = **Creative Commons 0** (or CC BY 4.0 and record the credit: sound name, uploader, link, license). Never use BY-NC sounds in a monetized Roblox game.
- **Sonniss:** perfect for your game, wrong for this vault. Its license forbids supplying the files "as sound effects" to anyone else, alone or in packs.
- **Pixabay:** same idea: fine inside a finished game, not as raw files in a bundle.
- Uploading any of these to Roblox counts as using them in your project; keep the source + license in [[Asset and License Log Template]] in case of a copyright claim.

## Credit line format (CC BY 4.0 Freesound sounds)
`"<Sound name>" by <username> (freesound.org/s/<id>/), licensed CC BY 4.0`
