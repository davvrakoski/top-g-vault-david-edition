# Free Selection, Cleanup and Utility Plugins

Workflow plugins that fix the boring parts of Studio. Free on 2026-10-25 (Roblox asset API).

| Plugin | Creator | What it does | Last update | Bundle-safe? | Link |
|---|---|---|---|---|---|
| Reclass classic | Elttob | Changes an instance's class but keeps its properties (Part to WedgePart, Frame to ImageLabel, ...) | 2025-09 | No - link only | https://create.roblox.com/store/asset/2867765019 |
| PartPicker | XAXA | Finds parts with matching properties, tags and meshes, so you can recolor/modify many at once | 2026-01 | No - link only | https://create.roblox.com/store/asset/2666837095 |
| Imiji | Elttob | Converts decal IDs to image IDs (the classic "my image won't show" fix) | 2025-09 | No - link only | https://create.roblox.com/store/asset/2849322379 |
| Local File Importer | XAXA | Test images from your PC in Studio before uploading | 2025-01 | No - link only | https://create.roblox.com/store/asset/3469049880 |
| OBJ Collision Gen | XAXA | Imports an .OBJ as a set of wedges, for precise collision on custom terrain shapes | 2022-11 | No - link only | https://create.roblox.com/store/asset/3413396608 |
| Shipool's Advanced Part Counter | ShipooI | Counts parts and more instance types in a selection | 2020-08 | No - link only | https://create.roblox.com/store/asset/855270560 |

## Notes
- **Tag Editor** (948084095, still free) is no longer needed: Studio's Properties window has a built-in **Tags** section for CollectionService tags ([[Properties window]]).
- Elttob's **Pick** and later paid plugins are not covered here; a DevForum poster warned that some of that creator's tools moved to paid. Reclass classic and Imiji were still free on 2026-10-25.
- Part counters are rough. For real performance numbers use the [[Developer Console]] and MicroProfiler.
