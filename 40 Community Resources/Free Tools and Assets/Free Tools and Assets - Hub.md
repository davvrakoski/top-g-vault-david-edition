# Free Tools and Assets - Hub

Free Studio plugins, code tools, Blender add-ons, art apps, textures, audio, fonts, icons and UI kits for Roblox, as recommended by the community (r/robloxgamedev, r/ROBLOXStudio, DevForum). Every license was read on the source's own page on **2026-10-25**, and every plugin's free status was checked with the Roblox asset API.

> **Start here:** [[Free Tools and Assets - License Rules for This Folder]] explains the **Bundle-safe?** column. "Free to use in your game" and "free to put in this vault" are not the same thing.

## Studio plugins
- [[Built-in Studio Tools That Replace Old Plugins]] - check these before installing anything.
- [[Free Building Plugins - Stravant, F3X and Archimedes]] - GapFill, ResizeAlign, Model Reflect, MaterialFlip, F3X, Archimedes, Studio Build Suite.
- [[Free Detail and Shape Plugins - Pipes, Curves, Cutters and 3D Text]] - Pipes, rope/curve drawing, Brick Cutter, CSG Curve Cutter, ThreeDText 2, Part Distributor, Resurface.
- [[Free Terrain, Lighting and Sky Plugins]] - Part to Terrain, triangle terrain, Tree Generator, Atmos, Light Editor.
- [[Free Selection, Cleanup and Utility Plugins]] - Reclass, PartPicker, Imiji, Local File Importer, part counters, Collaborative Notes, Rojo plugin.
- [[Free Rigging and Animation Helper Plugins]] - RigEdit Lite, Load Character Lite, Den_S Blender rig exporter.
- [[Free UI Plugins and UI Storybooks]] - AutoScale Lite, Roundify, Hoarcekat, UI Labs, Flipbook.
- [[Paid or Off-Sale Plugins Often Called Free]] - Moon Animator 2, Codify and others that are no longer free.
- [[Plugin and Free Model Safety Checklist]] - avoid backdoors from plugins and Toolbox models.

## Code tools and libraries
- [[Toolchain Managers - Rokit, Foreman and Aftman]] - pin tool versions per project (Rokit for new work).
- [[Lune - Run Luau Outside Studio]] - Luau scripts for build jobs and place-file edits; replaces Remodel.
- [[darklua - Transform and Convert Luau]] - require conversion, type stripping, release builds.
- [[Argon - Two-Way Sync Alternative to Rojo]] - two-way sync of code and instances.
- [[Moving an Existing Place to Rojo - syncback and rbxlx-to-rojo]] - get an existing game into files.
- [[Asset Pipelines as Code - Asphalt, Tarmac and Mantle]] - upload assets from a folder and generate ID modules.
- [[UI Libraries - Fusion, React-lua, Vide and Iris]] - MIT UI frameworks and when to use each.

## 3D, textures and skies
- [[Free Blender Add-ons for Roblox Work]] - official Roblox Blender Plugin, TexTools, UvSquares.
- [[Free 3D Apps Beside Blender - Blockbench, Instant Meshes and MeshLab]] - blocky modeling, auto-retopo, mesh repair.
- [[Free Texture Makers - Material Maker and Materialize]] - make your own PBR maps.
- [[More CC0 Texture Sites - 3DTextures.me and TextureCan]] - two CC0 sites plus the ShareTextures trap.
- [[HDRI to Roblox Skybox - Free Converter Workflow]] - turn a CC0 HDRI into six Sky faces.
