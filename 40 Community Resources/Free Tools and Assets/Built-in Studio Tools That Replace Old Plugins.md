# Built-in Studio Tools That Replace Old Plugins

Many "must-have plugin" lists (Reddit, DevForum, YouTube) are from 2018-2021. Studio has since built in a lot of what those plugins did. Fewer plugins = fewer things that can break or carry bad code ([[Plugin and Free Model Safety Checklist]]).

| Old plugin habit | Built-in now | Official note |
|---|---|---|
| Tag Editor plugin | **Tags** section at the bottom of the Properties window | [[Properties window]] |
| Align/distribute plugins | **Align tool** (align objects or groups on X, Y, Z) | [[Align tool]] |
| Custom pivot / rotate-around plugins | **Pivot tools** and pivot properties | [[Pivot tools]] |
| Rig-inserting plugins for basic dummies | **Rig Generator** (pre-built character models) | [[Rig Generator]] |
| Character-loader for testing outfits/sizes | **Avatar Settings** window (game-level avatar options) | [[Avatar Settings]] |
| OBJ-only mesh import plugins | **Importer** for .fbx, .gltf and .obj | [[Importer]] |
| Terrain generator / heightmap plugins | **Terrain Editor**: Import, Generate, Sculpt, Smooth, Paint, Flatten, Sea Level | [[Terrain Editor]] |
| Material-variant helper plugins | **Material Generator** (variants from text) | [[Material Generator]] |
| Texture painting for quick props | **Texture Generator** (textures from text or image prompts) | [[Texture Generator]] |
| Phone-preview plugins | **Device Simulator** | [[Device Simulator]] |
| "Test with a gamepad" workarounds | **Controller Emulator** (gamepad, VR, handheld, TV remote) | [[Controller Emulator]] |
| Lag-simulation scripts | **Network Simulator** (latency, jitter, packet loss) | [[Network Simulator]] |
| External-editor sync for scripts only | **Script Sync** | [[Script Sync]] |
| Rounded-corner image plugins (Roundify) | `UICorner` / `UIStroke` objects | [[UI appearance modifiers]] |

## When a plugin is still worth it
- Geometry jobs Studio can't do: GapFill, ResizeAlign, Model Reflect, Archimedes ([[Free Building Plugins - Stravant, F3X and Archimedes]]).
- Bulk selection by property (PartPicker) and class swaps (Reclass): [[Free Selection, Cleanup and Utility Plugins]].
- File-based workflows for teams: Rojo / Argon ([[Script Sync vs Rojo — 2026 Decision Guide]]).
