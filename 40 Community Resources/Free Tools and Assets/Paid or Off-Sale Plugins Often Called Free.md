# Paid or Off-Sale Plugins Often Called Free

Old "top 10 free plugins" videos, blog lists and Reddit replies still name these as free. On **2026-10-25** the Roblox asset API reported each one as **not free to take** (paid in USD, or off sale). Plugins on the Creator Store are priced in USD only ($4.99 to $249.99), so a Robux price no longer appears.

| Plugin | Creator | Status 2026-10-25 | Free alternative in this folder |
|---|---|---|---|
| Moon Animator 2 | xSIXx | Paid listing | Studio [[Animation Editor]]; Blender + Den_S exporter in [[Free Rigging and Animation Helper Plugins]] |
| Codify | cxmeel | Paid (itch.io and Creator Store); limited free demo, Luau output only | Write UI in code with a library from [[UI Libraries - Fusion, React-lua, Vide and Iris]] |
| Load Character Pro | AlreadyPro | Not free | Load Character Lite (free but unsupported) |
| DataStore Editor | sleitnick | Not free | Read data in a test place with your own admin script; never edit live data blindly |
| uiDesign Plus | Stelrex | Off sale | Roundify + built-in UICorner/UIStroke |
| Celestial Body Dragger, Tool Grip Editor, Show Decomposition Geometry | Maximum_ADHD | Not free | Studio: Lighting properties; the built-in decomposition-geometry view (Studio settings) |
| stravant's GeomTools Suite (fan bundle) | 7z99 | Off sale | Install the original stravant plugins: [[Free Building Plugins - Stravant, F3X and Archimedes]] |

## Rules of thumb
- **Never install a "free copy" of a paid plugin** from GitHub, Discord or a re-upload. A plugin can edit any script in your place; this is how backdoors get in. See [[Plugin and Free Model Safety Checklist]].
- Paid is not bad. If a paid plugin saves you hours, buy it from the creator's real listing. This folder just keeps free and paid apart.
- Prices and status change. Re-check the listing before recommending a plugin to a buyer of this vault.
