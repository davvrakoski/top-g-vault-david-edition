# FBX Asset Library - Hub
> [!topg] 10,040 FBX files · 53.0 GB · every file is CC0 (public domain), CC BY 4.0 (credit listed) or an original made for this vault, so it is legal to use, ship and include in a paid product.

## Sections
- [[Top G Originals - VFX Mesh Pack]]: 22 original VFX meshes (slashes, shockwaves, beams, lightning, orbs)
- **Kenney kits** (49 kits, 4,436 FBX): stylised buildings, cities, cars, weapons, characters with animations
- **Poly Haven** (26 categories, 521 FBX): realistic scanned props, furniture, rocks, plants, buildings parts
- Poly Haven 4K Pro: the same 521 realistic models with 4K textures, for Blender, Unreal and Unity users (521 FBX)
- [[100STYLE Mocap - Catalog]]: 100STYLE motion capture: 810 animation clips in 100 walking and running styles (CC BY 4.0) (810 FBX)
- [[Poly Haven Roblox-Ready - Catalog]]: Roblox-ready versions: under the triangle limit, scaled to studs, PNG texture maps (521 FBX)
- [[More Free Sources - Hub]]: More free sources: extra license-checked models from other open libraries (3,209 FBX)

## Rules for this library
- **FBX only** for models. Textures sit next to the FBX that needs them (PNG/JPG/EXR), plus a preview image.
- Every source and license is listed in [[Asset Licenses and Credits]].
- Not included on purpose: Mixamo, Quaternius (its license bans reselling the assets), CMU mocap (no resale), Sketchfab "free" models with mixed licenses, and any ripped game files.
