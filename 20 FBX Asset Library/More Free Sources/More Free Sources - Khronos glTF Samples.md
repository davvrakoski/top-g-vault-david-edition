# More Free Sources - Khronos glTF Samples
> [!topg] 26 models · 38 FBX files · 0.42 GB · CC0 1.0 or CC BY 4.0 (per model) · 14 fit Roblox's 20k-triangle limit as-is, every other one has a ready `_Roblox20k.fbx` copy

High-quality PBR showcase models from the **Khronos Group glTF Sample Assets** repo: furniture and lamps, a chess set, helmets, boom box, lantern, toy car, traffic cone, food and a fish. Each model's license comes from its own `metadata.json`.

> [!warning] Some models are **CC BY 4.0 — attribution is REQUIRED**. The exact credit line is in each model's `LICENSE.txt` (and in the "License" column below). Put it in your game's credits/description.

## License
- Licenses read per model from `Models/<name>/metadata.json` on 2026-10-25. Only CC0-1.0 and CC-BY-4.0 models were taken.
- Left out: anything NC/SA (DamagedHelmet, IKEA Playset), custom licenses (Sponza/Crytek, Stanford dragons, Sony Duck, Poser BrainStem, 3DRT VirtualCity) and models carrying Khronos/Cesium/UX3D logos.
- CC BY 4.0 = give credit, link https://creativecommons.org/licenses/by/4.0/, and say it was changed (converted to FBX).
- The rigged **Fox** is in `Animals/Fox/` (model CC0 by PixelMannen, rig & animation CC BY 4.0 by tomkranis, glTF conversion CC BY 4.0 by @AsoboStudio and @scurest). It is authored in centimetres-like units (≈140 units long): scale it down after import.

## Roblox import tips
1. Studio → **Avatar/Model tab → Import 3D** (3D Importer) → pick the `.fbx`. Keep the `textures/` folder next to the FBX so the importer finds the maps; if a texture does not come in, add a **SurfaceAppearance** and set ColorMap / NormalMap / RoughnessMap by hand from `textures/`.
2. Roblox's limit is **20,000 triangles per MeshPart**. Items over the limit ship with a ready `*_Roblox20k.fbx` copy (auto-decimated to about 19,500 triangles); use that one in game and keep the full one for renders/thumbnails.
3. Files are in **metres** with the origin at the bottom centre (kits keep their authored pivots so pieces snap). If an import is tiny or huge, set the importer's scale or resize the MeshPart (1 stud ≈ 0.28 m).
4. Set **CollisionFidelity = Box/Hull** and **RenderFidelity = Automatic** on big scans to save memory; anchor static props.
5. Roblox textures max out at 1024 px in game, so the 2048 px maps here are downscaled on upload — no need to resize first.
