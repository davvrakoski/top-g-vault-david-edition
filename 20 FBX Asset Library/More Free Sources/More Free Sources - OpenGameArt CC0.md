# More Free Sources - OpenGameArt CC0
> [!topg] 58 packs · 1998 FBX files · 0.41 GB · CC0 1.0

Hand-picked **CC0** packs from OpenGameArt.org by well-known authors: **Yughues / Nobiax** (realistic crates, barrels, barriers, pallets, trash, rocks, plants, pillars, modular building), **Keith at Fertile Soil Productions** (big modular dungeon/village/house/temple/terrain/racetrack kits), **Kay Lousberg** (KayKit packs), **rubberduck** (industrial, mine, pipes, sci-fi container, mossy rocks), **Lucian Pavel** (western props, rifle, flamethrower) and **Clint Bellanger** (rope fence).

## License
- Each pack page on OpenGameArt lists **CC0** as its only license (checked 2026-10-25), and the author is the uploader. Yughues' own readme repeats the CC0 text; KayKit packs carry Kay Lousberg's CC0 license file.
- Credit not required. Suggested: "<Pack> by <Author> (OpenGameArt), CC0".
- Left out on purpose: packs with third-party or unclear parts (a castle tileset that reuses other people's textures, a spaceship pack containing a Star Wars TIE Fighter, a "Dark Souls"-inspired sword), currency/banknote art, cannabis plants, a beer bottle, and anything by Kenney/Quaternius (already in the vault / excluded).

## Files

## Roblox import tips
1. Studio → **Avatar/Model tab → Import 3D** (3D Importer) → pick the `.fbx`. Keep the `textures/` folder next to the FBX so the importer finds the maps; if a texture does not come in, add a **SurfaceAppearance** and set ColorMap / NormalMap / RoughnessMap by hand from `textures/`.
2. Roblox's limit is **20,000 triangles per MeshPart**. Almost every kit piece is far below it; the table flags any pack with pieces over 20k (decimate those in Blender before import).
3. Files are in **metres** with the origin at the bottom centre (kits keep their authored pivots so pieces snap). If an import is tiny or huge, set the importer's scale or resize the MeshPart (1 stud ≈ 0.28 m).
4. Set **CollisionFidelity = Box/Hull** and **RenderFidelity = Automatic** on big scans to save memory; anchor static props.
5. Roblox textures max out at 1024 px in game, so the 2048 px maps here are downscaled on upload — no need to resize first.
