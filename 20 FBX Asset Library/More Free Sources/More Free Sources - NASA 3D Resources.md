# More Free Sources - NASA 3D Resources
> [!topg] 74 models · 111 FBX files · 0.58 GB · NASA media (no US copyright) - credit NASA · 37 fit Roblox's 20k-triangle limit as-is, every other one has a ready `_Roblox20k.fbx` copy

Rockets, launch hardware, spacecraft, satellites, rovers, spacesuits, ground stations and tools from **NASA 3D Resources** (science.nasa.gov/3d-resources, mirrored at github.com/nasa/NASA-3D-Resources). Mostly low/mid-poly game-friendly models — perfect for space, sci-fi and "space centre" Roblox maps.

The repo README says the assets are "free and without copyright".
- **Only models whose NASA page credits a NASA source** (NASA centres / NASA staff) were included. Models credited to JPL/Caltech, outside companies (e.g. DigitalSpace Corporation, Ball Aerospace) or with no source credit were left out.
- **Credit "NASA"** as the source. **Never imply NASA endorses** your game.
- The NASA insignia ("meatball"), logotype ("worm") and seal are protected and **not** public domain. Some textures show them as on the real hardware: do not use them as a logo, on merch or in thumbnails/ads; paint them out for zero risk.

## Roblox import tips
1. Studio → **Avatar/Model tab → Import 3D** (3D Importer) → pick the `.fbx`. Keep the `textures/` folder next to the FBX so the importer finds the maps; if a texture does not come in, add a **SurfaceAppearance** and set ColorMap / NormalMap / RoughnessMap by hand from `textures/`.
2. Roblox's limit is **20,000 triangles per MeshPart**. Items over the limit ship with a ready `*_Roblox20k.fbx` copy (auto-decimated to about 19,500 triangles); use that one in game and keep the full one for renders/thumbnails.
3. Files are in **metres** with the origin at the bottom centre (kits keep their authored pivots so pieces snap). If an import is tiny or huge, set the importer's scale or resize the MeshPart (1 stud ≈ 0.28 m).
4. Set **CollisionFidelity = Box/Hull** and **RenderFidelity = Automatic** on big scans to save memory; anchor static props.
5. Roblox textures max out at 1024 px in game, so the 2048 px maps here are downscaled on upload — no need to resize first.
