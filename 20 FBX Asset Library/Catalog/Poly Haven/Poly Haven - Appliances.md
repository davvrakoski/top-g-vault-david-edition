## Files

## Roblox import
1. **Import 3D** the `.fbx`. Over 20k triangles? Blender → Decimate modifier (ratio 0.3–0.5) → re-export FBX.
2. Build a **SurfaceAppearance**: `_diff` → ColorMap, `_nor_gl` → NormalMap, `_rough` → RoughnessMap, `_metal` → MetalnessMap (convert any `.exr` to `.png` first).
