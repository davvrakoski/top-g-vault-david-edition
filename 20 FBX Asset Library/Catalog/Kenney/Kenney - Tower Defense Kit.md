## Roblox import
1. Studio → Avatar/Home → **Import 3D** → pick the `.fbx`.
2. Kenney kits share one `colormap.png`: import it once and set it as each MeshPart's `TextureID` (or use SurfaceAppearance).
3. Scale: Kenney units are metres; Roblox 1 stud ≈ 0.28 m, so scale ×3.57 for real-world size.
